## 의미 검토

- KR1.25 MAP218개, KR4.91 그래픽·매뉴얼, NA495/후대 RTK 자료를 구분한다. 한국 도시 지형은 UNRESOLVED이며 북미 지형이나 임시 포털을 한국 복원 정답으로 채택하지 않는다.
- 한국491 텍스트 Effect.tbl과 현대 Nexus 도구 포맷을 구분한다. sound003/160ms, 뷰어1024ms, 서버35프레임을 한국 원작 실측값으로 승격하지 않는다. WAV163개 보유와 사건별 호출/청각 출력 확인도 분리한다.
- 동봉 한국 문서의 좌표·시대 충돌, P1998 ASCII 이름, spark sound55/701 차이를 평균·자동 통합하지 않는다. 공식 연혁과 사용자 사진의 UI 요구도 개별 규칙/촬영 연대 확정으로 확대하지 않는다.
- 기본 프로필2001년 말은 잠정 제안이며 목표1998~2001, 네 직업, 사진 UI, Windows/Android, 오프라인, 같은 계정 순차 이어하기를 보존한다.
- NEXT_P2는 입력ID·해시·독립 기대결과·실패/취소·남은 장애를 제공한다. 임시 작업경로가 다음 환경에 유지된다고 약속하지 않으며, P1998 선택파일을 전체 실행가능 checkout이나 한국/Android 완제품이라고 부르지 않는다.

## 검사의 한계와 저장 시 유의점

독립 검토자의 직접 파일 해시 재계산은 현재 접근 가능한110개다. 이후 통합 담당은 `validate_step01.py`에 시청각 도구의 `sources[].files[].local_path` 검사도 추가했다. 수정한 실제 코드와 최신 VALIDATION의211파일/실패0 결과를 읽어 확인했다. 그211개를 독립 검토자가 모두 재계산했다고 주장하지 않는다. 내부 member2,204개의 전수 재해시는 이 최종 검사 프로그램의 범위가 아니며, 각 담당의 별도 바이트/manifest 검사 근거를 참조한다. 이번 독립 검토도 전체 압축 재해독이나 기존 게임 재감사를 반복하지 않았다.

확장자·비밀키 패턴 검사는 알려진 형식의 탐지이며 모든 종류의 비밀정보 부재를 수학적으로 증명하지 않는다. 본문/표와 공개 파일 범위도 함께 읽었다. 역사값의 정확성, 렌더링·오디오, 원본 기준본, 실제 Windows/Galaxy, 실인증 기기 왕복은 검증하지 않았고 NOT_RUN/미확인으로 유지한다.

최종 저장 직전에 STATE의 검증 대기 표기를 실제 완료 상태로 갱신하고, 최종 수정과 이 검토서를 포함한 산출물에 `validate_step01.py`를 다시 실행해 해당 입력지문을 기록한다. 원격 저장 커밋/파일 지문 확인은 통합 담당의 저장 영수증으로 별도 증명한다. 독립 검토자는 원격 게시를 수행하거나 게시 완료를 확정하지 않았다.

검토 종료점은 P0/P1 결과다. 새 게임 코드·기준 서버 실행·APK/EXE 빌드·배포·P2로 진입하지 않았다.
