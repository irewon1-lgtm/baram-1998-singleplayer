# 바람의나라 G2 r15 설치 후보

현재 Godot 프로젝트에서 국내성·부여성, 16개 야외권역, 12개 4층 던전을 연결한 오프라인 싱글플레이입니다. 새 캐릭터는 주막에서 시작합니다. 지도에서 도시의 길드·상점·출구를 확인하고 남문 초보 사냥터에서 성장할 수 있습니다.

## Windows

1. ZIP 전체를 새 폴더에 풉니다.
2. `baram-p3-playable.exe`를 실행합니다. 별도 Godot 설치는 필요 없습니다.
3. 기존 P3 보수본의 저장 경로를 유지합니다. 기존 캐릭터는 **이어 하기**를 선택합니다.

사용자 저장은 `%APPDATA%\baram_rebuild_p3repair_001\gameplay-p3\characters`에 있습니다. 업데이트 전 게임을 종료하고 이 폴더를 복사해 두면 별도 백업이 됩니다. 실행 파일 폴더를 바꾸어도 사용자 저장 경로는 같습니다.

## Android

기존 `com.irewon.baram.p3repair20261016` 앱을 **삭제하지 않고** APK를 업데이트 설치합니다. 기존 서명키를 유지했으며 버전 코드는 7, 버전 이름은 `0.3.0-g2`입니다. 설치 시스템의 안내를 따릅니다.

다른 패키지나 다른 서명의 과거 앱 저장이 자동으로 옮겨지는 기능은 없습니다. 서명 오류가 나면 삭제 설치로 해결하려 하지 말고 기존 앱과 데이터를 보존합니다. Android 앱 데이터는 앱 전용 공간에 있습니다.

## 조작과 새 콘텐츠

- 방향키·화면 지면 클릭/드래그: 이동. 지도에서도 목적지를 누를 수 있습니다.
- Space 또는 **공격**: 가까운 적 공격. **기술** 버튼과 기술 패널: 배운 기술 사용.
- Enter 또는 **대화**: NPC 서비스. Z 또는 **줍기**: 가까운 전리품.
- Tab: 물품·기술·장비·능력치 패널 전환. Esc/닫기/취소: 대화 종료.
- **저장 · 처음으로**: 저장 후 메뉴. 자동 저장도 유지합니다.
- 지면의 자원을 누르면 가까이 이동해 채집합니다. 채집한 자원은 지역 제작 NPC의 재료입니다.
- 방문한 권역은 길잡이·나루지기의 유료 이동 목록에서 다시 갈 수 있습니다.
- 상점 장비는 직업·레벨·능력치 조건을 확인합니다. 물품 패널에서 장착·사용하고, 가방이 차면 창고 NPC에 맡길 수 있습니다.
- 지역 의뢰는 길잡이·상인·제작 NPC에게 수락하고 목표를 수행한 뒤 보고합니다. 던전 아래층의 수문장은 장비를 떨어뜨립니다.
- 척후·철갑·맹독·저주·결박 등은 사거리, 방어, 이동 속도와 상태 공격이 다릅니다. 회복·해독/상태 해제 도구와 배운 기술을 함께 사용합니다.

## 저장 이전과 검증 범위

G1 저장을 읽으면 명시된 지도 좌표 변환을 적용합니다. 실제 저장을 확정하기 전에 기존 원본과 백업을 `.pre-migration-<SHA256>` 파일로 보존합니다. 몬스터의 기존 ID·생사·체력·타이머, 소지품·장비·기술·의뢰·돈은 유지합니다. 새 지도에 들어갈 때 필요한 새 몬스터만 생성합니다. 현재 세대 저장은 좌표를 두 번 옮기지 않습니다.

Linux에서 실제 파일 이전·중단 지점 복구와 GUI 입력을 시험했습니다. Windows EXE 내장 자료와 APK 자료의 일치도 별도로 확인했습니다. **실제 Windows 실행, Android 설치·업데이트·저장 유지, Galaxy, 운영체제 한국어 IME와 물리 음향은 미실행입니다.** 기기 검증이 끝난 정식 배포본으로 판정하지 않습니다.

같은 계정의 Windows→Android→Windows 인증 왕복은 승인된 게임 인증·저장 서버가 확인되지 않아 차단 상태입니다. 이 후보의 로컬 저장·캐릭터 이어하기는 온라인 계정 동기화가 아닙니다.

계획 ID와 B5→B6 순서는 유지합니다. 세부 전투 밸런스와 원본 지도 사이 접합부의 미술 조정은 남아 있습니다. 실제 장시간 성능 결과는 동봉 결과 보고서와 증거 파일을 따릅니다.

저장 경로 근거: [Godot 4.6 데이터 경로 문서](https://docs.godotengine.org/en/4.6/tutorials/io/data_paths.html).
