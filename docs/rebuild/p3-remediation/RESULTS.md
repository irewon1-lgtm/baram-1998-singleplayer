전체 판정은 아직 진행 중이다. 원격 최신 인계 1a8df157에서 이어받아 기존 입력 b97c533e 해시를 확인했다. 사용자 사진과 기존 Android 화면은 실제로 열어 비교했다.

지도: 2001년 공식 지도 P15-ARCMAP-0579ce2fedc9 / 7dd51290d10b의 원본 ZIP과 PCX를 인계 파일에서 해시 확인 후 직접 열었다. 궁성 중앙의 해자·여러 주거 구역·수로와 외곽 지형이 현재 64×64 십자형 배치와 다르다. 공식 그림에 셀 좌표·원본 MAP ID가 없어 현재 충돌·출구를 원본으로 확정할 수 없다. 이번에는 저장 좌표를 임의 이동하지 않고 현재 지도와 출구 이름·좌표를 보고 직접 걸어가는 지도 UI를 연결했다. 원작 도시 복원 결함 P3-FIX-09는 기능 보수와 독립적으로 BLOCKED_ORIGINAL_MAP_GRID_CORRESPONDENCE / NEEDS_USER_VALIDATION을 유지한다. 새 지형이 원작과 같다고 보고하지 않는다.

독립 참고 검색에서 넥슨 사이트의 2018~2024 사용자 답변은 목표시기와 다르고, 2017 사설서버 지도도 다른 출처이므로 역사적 정답에 채택하지 않았다. 상위 근거인 2001 공식 그림을 비교 기준으로 유지했다.
