# P3 보수 검증 계약

입력 ZIP·앱소스와 최신 인계문서 해시 확인. 기존 코드와 자료 보존. 신규 사용자 승인이 AGENTS의 과거 P0/P1 범위 제한을 이번 P3 보수에 한해 대체한다.

|단계|입력/방법|합격 기준|상태|
|---|---|---|---|
|입력/공격|동일 Game.command와 실제 InputEvent|미선택 공격·HP/XP/드롭, 벽/거리/세대/중복 거부|NOT_RUN|
|UI/이동|최종 소스 Godot GUI, 3해상도|4패널·전신착용, 홀드/회전/해제, 경로, 보간, 충돌|NOT_RUN|
|설치본|새 APK 설치·Windows 내장PCK|실제 바이트 해시와 핵심 동선·재실행 증거|NOT_RUN|
|실기기|Galaxy·native Windows·OS IME·물리청취|실기기에서 직접 수행한 증거|NOT_RUN|

참고 사진은 직접 열어 확인했다. 갈색 장식 테두리·상단 종이 두루마리·오른쪽 상태·왼쪽 하단 대화창·전신 장착슬롯을 기준으로 삼는다. 그림 원본 마스크 3FAIL은 보존하고 패널 경계는 명시적인 코드 재구성으로 제공한다. 기존 도시 원본 대응은 UNKNOWN이며 이번 기능 성공으로 고증 PASS를 만들지 않는다.
