# P3 보수 영향 검증

자동 GUI, 명시적 분기 fixture, 호스트 실행, 실 OS 이벤트, 사람 손 조작을 분리한다. 기존 보고 실패는 USER_REPORTED/STATIC_CAUSE로 접수했다. 이전 APK를 현재 실기기에서 재현했다고 하지 않는다. 참고 사진3장과 기존 Android 화면을 실제 열어 읽었다.

실패 보존: 반격 예약을 중복 player hit로 오인한 비교, 외부 경로 읽기 보안의 올바른 거부, 반복 시험 revision 충돌, 이름 RNG에 의존한 드롭 fixture, 스크롤 밖 닫기 클릭, 첫 자연 조작기 경로 오류, 저장 직전 snapshot 시각 경합, 오디오 호스트 모듈 누락, Android30 OS ANR의 원본 로그를 별도 증거에 보존했다. 게임 드롭 확률·저장 안전·학습 조건을 완화하지 않았다.

저장 parser와 원자저장 모듈은 해시 불변. 기존83검사를 중복 실행하지 않았다. 변경된 입력/전투/단축키/장비/UI와 연결된 저장만 재검증했다. 강제 종료 중 쓰기·symlink·물리 IME 등 새 플랫폼에서 실행하지 않은 조건은 과거 PASS로 대체하지 않는다.

실사용 판정은 NEEDS_USER_VALIDATION. 원작 도시 구조와 장비/UI 시각 승인은 별도다. 자동 검사 숫자는 사용자 직접 조작 PASS가 아니다.
