## 어떻게 플레이하는가

국내성 작업용 재구성(32,36)에서 평민Lv1로 시작한다. 목도·초보옷은 선언된 시작 장비이며 돈/XP/공격기술을 몰래 지급하지 않는다. 북문(32,1), 남문(32,62), 동문(62,32), 서문(1,32)을 걸어서 넘으면 각각 다른 초보 사냥터로 간다. 토끼는5XP·토끼고기, 다람쥐는2001선정10XP·도토리를 준다. 드롭85%는 원작값이 아닌 작업용 확률이다.

Z/줍기로 전리품을 얻고 국내성 장터 식재료상(27,33)에 도토리5전·토끼고기8전으로 판다. 대장간 입구(48,19)의 털보에게 목검20전을 주고 사서 장착한다. 갑옷상 떼보(25,29), 주막 입구(15,15)의 왈숙은 서로 다른 재고를 가진다.

주술사길드 입구(48,54)로 들어가 해두(실내10,7)에게 평민Lv5 이상에서 전직한다. 누리의기원은Lv5·도토리10/토끼고기10, 주작 수호의 화염주는Lv6·도토리10, 비영사천문은Lv5·도토리10/토끼고기10을 각각 확인하고 소모한다. 다른 세 직업 사범은 각각 태백/마로/진선이고 첫 누리의기원은 전사Lv10·도적Lv8·도사Lv5로 다르다.

대표 자연 진행은 재료 수집과 수리비 마련 중 실제Lv10까지 갔다. 도토리4개를 팔아 목검을 사고, 나중에 추가30개 판매150전으로 실제 손상 목검을 수리했다. 총104킬,88번 줍기,1회 사망/부활,915XP. 이는 Lv5 전직과 Lv5 모든 기술 습득을 혼동한 결과가 아니다. 다른 세 직업은 명시된 분기 fixture 시험이며 자연 육성으로 세지 않았다.

기술1~9 단축키·기술 패널은 같은 명령을 사용한다. HP/MP와 실제 명중·회복·유한 효과·가상 음향이 연결된다. 비영사천문의 동서남북 목적지/좌표는 다르다. 저장하고 처음으로→종료→다시 실행→이어 하기에서 직업·XP·HP/MP·금전·장비·아이템·기술·단축키·좌표·바닥 전리품·몬스터/지연 행동을 보존한다. 일반 UI 새 프로세스에서 저장 순번 이후의 행동도 재개했다.

## 정상 동작을 확인한 범위

고정 소스의 Linux 일반 마우스/키 이벤트 생성·취소·이동·저장·재시작 PASS. 정상 명령 자연 진행과 실제 GUI 최종 상태의 모든 필드는 차이0. 최종 Windows EXE의 내장 PCK를 Linux Godot로 열어 같은 자연 명령을 실행했고, 실제 Windows 실행으로 세지 않았다. 단축키 회복/귀환·네 패널·저장14항목은 정상 육성 저장을 읽은 명시된 GUI 입력 회귀다.

실제7자식프로세스 강제종료를 포함한 저장83회귀 PASS. JSON 소수 타이머 재해석의 체크섬 오류를 P3 전용 마이크로초 표현으로 수정했다. P2 저장은 그대로다. 최종 포함물763개는 JSON 해시·PNG 가시RGBA·음향 참조/재생 길이로 검증했다. 기본 WAV importer는 QOA를 사용하므로 패키지 PCM이 원본 바이트와 동일하다고 하지 않는다. 원본 PCM은 별도 입력에 보존되어 있고, 내장 QOA의 실제 가상 출력도 확인했다. 물리 청취는 미실행이다.

Android의 엔진·입력·저장 체크포인트와 PID, 전체logcat을 실행 전부터 수집했다. 중간 시험에서 화면 밖 터치 버튼과 느린 프레임의 첫 이동 누락을 고쳐 최종 빌드로 다시 시험했다. Android 최종 결과와 비공개 전달 영수증은 PLAYTEST_RESULTS / DELIVERY에 기록한다.
