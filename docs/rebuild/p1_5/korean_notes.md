# 한국 문서·시대·공식 원문 보완 결과

이번 조사 판정은 PARTIAL이다. 공식 원문을 실제 확보해 많은 필드의 근거를 바꿨지만 원작 서버의 모든 동작·확률·스폰이나 목표 판본 전체를 확정한 것은 아니다. 새 게임·기준 서버·클라이언트 실행과 기기 시험은 NOT_RUN이다.

## 실제 확보·해독과 신규 기여

- 기존 KR4.91 묶음의 TXT 11개 전체를 CP949 strict로 읽고 BMP 3개를 확인했다. 이전 열 군데 문단 확인을 넘겨 도사 36개·주술사 42개 기술 설명/학습 표, 중복 요약을 제외한 위치 43개, 숫자 장비 표와 드롭 후보를 구조화했다. 출처·해시·원문 줄은 `selected_content/kr_documented_fields.jsonl`에 있다. 이 자료의 다수는 시대가 미확정이므로 최신 한국 원작값으로 자동 채택하지 않았다.
- 묶음 안 `바람의나라가이드.txt` 끝에 **1997-05-07 22:00**이 실제 적혀 있다. 초보 메뉴얼 둘에는 도사 미출시 문구가 있다. 따라서 컨테이너 4.91이라는 이름으로 이 모든 문서를 1998~2001 자료라고 판단할 수 없다. 같은 옛 가이드 계보와 복사된 마법 표도 독립 증거로 합산하지 않았다.
- 이전에 접근하지 못했던 Wayback 원문을 다른 정상 경로에서 확보했다. CDX 결과 248개 URL 중 필수 하위 범위에 해당하는 **122개 공식 HTML**을 고정 캡처 URL로 실제 취득·해시·CP949 strict 해독했다. 그중 학습·몬스터 표를 담은 25개 원문에서 **928개 활성 행**을 정규화했다. 목록 발견이 아니라 실제 원문 바이트와 행을 대조했다.
- `selected_content/kr_official_core.jsonl`은 기술 377행과 몬스터/보상 551행이다. 서로 다른 시기의 동일 개체가 포함되므로 이 수치를 서로 다른 기술/몬스터 전체 수로 세지 않는다. 원문 이름·수치·원문 줄·원문 SHA와 향후 필요한 구현이 있다. HTML 표에 없는 스폰 개수·상한·정확한 AI 간격·명중 시점·드롭 수량은 null이다.
- 별도 `selected_content/kr_official_flow.jsonl` 20행에는 생성 항목, 원래 계정/복구 체계, 특성치·경험치 교환, 국가별 귀환과 성황령/비영사천문의 목적지 개념을 정리했다. 문서의 항목 번호를 실제 프로그램이 강제하는 이벤트 순서로 오독하지 않았다.
- 생성 화면의 새 경로가 막힌 뒤 옛 경로의 실제 GIF를 추가 확보했다. 요청은 2000년 보관본이었지만 실제 응답은 **2001-06-07** 캡처이며 이 날짜를 사용했다. `kr_official_creation_visual.jsonl` 1행은 성별 버튼·좌우 화살표·현재 보이는 얼굴 4개·국가 아이콘 2개·신수 아이콘 4개·OK/CANCEL만 관찰값으로 채택한다. 보이는 얼굴 4개를 전체 얼굴 종류 수로 바꾸지 않았으며 실제 선택 순서·클릭 좌표·초기 장비는 미상이다.
- 2001 공식 기술 표에서 기술별 GIF 경로를 찾았다. 효과 경로 **52종, URL 64건**을 실제 요청했다. **GIF 정상 취득 60건 / 고유 바이트 51개**, 옛 경로 404 3건, 이미지 형식 해독 실패 1건이다. GIF에 선언된 프레임 지연은 보존했으나 원작 시전/타격/음향 지연으로 채택하지 않았다. 요청한 캡처 연도와 실제 반환된 캡처 연도를 분리했으며 2002년 반환 바이트를 2001년 자료로 자동 승격하지 않았다. 효과 프레임 비교와 기술 동작 문서의 추가 의미 판독은 별도 자산 산출물을 따른다.
- 추가로 당시 화면의 실제 첨부 그림을 취득했다. 2014년 재게시 글의 연대 설명과 그림 안 날짜를 구분했다. 2001년 게시 화면에는 부여성북쪽·좌표 0072/0015와 오른쪽 장비 화면이 실제 보인다. 튜토리얼의 실제 게임 화면은 6장이고 함께 실린 만화는 게임 화면 증거에서 뺐다. 4.70 신국내성 지도는 500×500 **그림 크기**이며 게임 타일 치수로 바꾸지 않았다.

## 바로 사용할 수 있게 된 예와 남은 제한

- 네 직업의 학습 레벨·금전·재료가 서로 다른 공식 표를 확보했다. 주술사 공격 계열과 신수 구분, 전사/도적의 개별 기술, 도사 회복/해제 기술이 연결된다. 전직업 공통 허용이나 레벨 1 자동 지급으로 보완하지 않는다.
- 공식 표의 공통 기술 세 가지는 레벨 5와 명시적인 무금전·도토리/토끼고기 조건을 보여준다. 원문에서 명시한 0원은 미상값을 0으로 채운 결과와 다르다.
- 왕초보의 다람쥐·토끼, 쥐굴의 변종과 뱀굴, 지역별 해골/유령, 일본과 북방 등의 구분을 구조화했다. 서생원 산삼 **10%**라는 명시 수치도 확보했다. 이것만으로 전체 드롭 표의 독립/배타 판정, 수량, 무드롭 결과까지 확정하지 않는다. 금전과 물품을 분리했고 은전/은전뭉치의 아이템/통화 구분은 미확정으로 남겼다.
- 원문 자체의 이상값도 보류했다. 백호왕 XP 800, 쥐왕 XP 1000, 최강다람쥐 XP 100은 원문 값은 보존하되 채택 XP에서 제외했다. 임의로 ‘만’을 붙이거나 평균 내지 않았다. 여러 변종/드롭을 한 셀에 쓴 행은 하나의 괴물·아이템으로 만들지 않는다.
- 제작/조합/수리는 시대 존재와 상점 기능의 근거가 늘었지만 개별 제작 성공률·수리비 산식·실패 손실은 이 문서 범위에서 확인되지 않았다. 공식 연혁의 2000년 조합과 2005년 생산을 구분하되 2005년 이전 모든 NPC 업그레이드가 없었다고 단정하지 않는다.
- NPC 대화는 실제로 보이는 짧은 튜토리얼 문장만 원문으로 분리했다. 옛 공략의 플레이어 명령과 NPC의 실제 발언은 다르다. 기능 보존형 한국어 재구성 4개는 원문 null·재구성값 별도이며 원작 대사라고 표시하지 않는다. 전체 NPC 대화/분기·외형 ID/좌표/모션 복원 완료가 아니다.

## 판본과 선택 방지 장치

공식 원문에도 2000/2001 값이 다르다. 예를 들어 다람쥐 XP 5/10, 전사 대지의기원 도토리 80/70, 건곤대나이 금전 5000/1500이 있다. `research_official_core.json`의 `epoch_conflicts`에 실제 후보와 출처 ID를 두었다. 각 행은 `KR_GUIDE_2000_SNAPSHOT` 또는 `KR_GUIDE_2001_SNAPSHOT`에만 적용되고 `require_profile_dispatch=true`, `global_default_selected=false`, `target_profile_resolution=UNRESOLVED`다. ‘최근 보관된 웹페이지’가 ‘선택한 원작 서버 패치’라는 뜻이 아니다. source_family는 모두 같은 공식 가이드 계보로 취급한다.

## 실제 검사와 수정

독립 DOM 검사에서 두 가지 추출 오류를 찾아 고쳤다. HTML 주석 안 비활성 파이어볼 2행과 몬스터 5행이 잘못 활성화되던 경로를 줄 위치를 보존하는 주석 마스킹으로 차단했다. 닫는 tr/td가 빠진 원문의 활성 7행도 일반적인 행/셀 경계 처리로 회수했다. 보상 칸의 br 구분, 금전/물품, 변종 묶음도 수정했다.

최종 `official_independent_review.json`은 원문 25개·활성 DOM 행 예상 928개와 실제 928개를 대조했고 누락/추가 0개였다. 이 PASS는 원문 표 필드의 대응 범위이며 원작 서버·프로필 선택·게임 실행 PASS가 아니다. 재사용 가능한 정적 추출기는 `tools/rebuild/p1_5/parse_official_core.py`와 `build_official_flow.py`다. 입력 원문 해시를 실제 확인하며 네트워크나 게임을 실행하지 않는다.

## 재개와 정확한 관측 과제

1. 기본 복원 프로필의 시대와 도시 지도 대응을 결정한다. 공식 PCX 지도 묶음과 같은 시기 NPC/사냥터 표를 한국1.25 MAP와 비교하되 타일·통행·출입 칸이 같다고 전제하지 않는다.
2. 공식 GIF→한국 원본 프레임의 대응이 확인된 기술부터 P2 입력으로 사용한다. 동일 번호라는 이유로 매칭하지 않는다. GIF 시간과 실제 명중/음향 시점은 분리한다.
3. 소리 ID, 판정 조건과 드롭/조합 확률 모델, 완전 대사 분기는 원본 실행을 별도로 승인받은 뒤 정확한 판본·행동·관측 로그로 보완한다. 정적 그림이나 네트워크 지연으로 숫자를 만들지 않는다.
4. 입력 보관 원본은 비공개 인계 묶음과 Library ID/해시로 회수한다. 이 문서의 임시 작업 경로는 다운로드 보장을 대신하지 않는다. 실제 계정 동기화와 Windows/Galaxy 실행은 미실행이다.
