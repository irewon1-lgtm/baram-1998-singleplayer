# P1.5에서 P2로 넘기는 변경·관측 계약

이 문서는 입력 인계다. P2 실행 승인이 아니다. 기존 `step01/NEXT_P2.md`의 여섯 단위를 유지하고 아래 입력·장애를 보완한다. 최신 STATE와 INPUT_MANIFEST, REPORT를 함께 읽는다. 한국 1998~2001 개인용 복원·오른쪽 UI·두 플랫폼·오프라인·순차 이어하기 요구는 그대로다.

## G0 — 수신 환경에서 먼저 확인할 것

1. 계획 브랜치의 최신 커밋을 읽고 인계 기준으로 reset하지 않는다. 과거 P0/P1 원장과 실패 기록을 유지한다.
2. `INPUT_MANIFEST.json`의 Library 원본 ID·SHA와 비공개 인계 묶음의 상대 경로·SHA를 실제 바이트에 대조한다. 현재 Work의 42개 원본/2,204개 멤버 접근 성공은 다음 Codex 환경의 접근 성공이 아니다. 원본은 공개 Git에 없다.
3. 비공개 데이터는 `selected_content/` 아래 원래 상대 경로로 읽는다. 공개 catalog는 원문 데이터의 대체물이 아니다. 데이터가 없으면 누락으로 표시하고 기본값을 생성하지 않는다.
4. 정적 컨테이너 재현은 원본 사본에 `recheck_archives.py`를 사용한다. `--legacy-parser-dir`의 세 reader 파일은 원장 SHA로 고정한다. 원본 파일명은 보관 파일명 그대로 사용하고 결과는 별도 private-work에 쓴다. 도구가 만든 `input_map.json`은 현재 환경의 경로 지도일 뿐 지속 식별자가 아니다.
5. 기존 전체 원장 검사는 `validate_step01.py --input-map <현재경로지도> --output <새결과>`로 수행한다. 과거 VALIDATION은 덮어쓰지 않는다. `prepare_handoff_inputs.py`의 기존 원장 전용 경로표(정확히2,489 ID)를 사용한다. 신규 자료까지 포함한 import용 경로표를 이전 원장에 넘기면 알려지지 않은 ID로 거부되는 것이 맞다. `--scope-input` 통과가 전체 통과를 대신하지 않는다. 필수 누락은 BLOCKED, 바이트/형식/참조/지문 불일치는 FAIL, 미실행은 NOT_RUN이다.
6. `handoff_input_contract.json`의 현재 경로 복원 절차와 import용 전체 경로표를 사용해 `import_dry_run.py`로 비공개 선정 표를 읽고 원본·재구성·타권역 참고·미지원 의미를 구분한다. 무결성 검사와 한국 게임 의미 연결 준비도를 별도로 보고한다.

원본 바이너리나 외부 SQL/설치 프로그램을 그대로 실행하지 않는다. 이번에 정적 확보한 참고 서버는 실행하지 않았다. 전체 소스 확보, 의존 패키지 설치, 호환 클라이언트 확보, 실제 기준본 로그인은 각각 별개다. 민감 외부 DB·기본 비밀번호 설정과 임시 파일 전송 영수증은 인계 제외 목록을 따른다.

## P2-01 — 한국 지도

- 입력: LIB-009 한국1.25 MAP218, LIB-010 원본 그래픽/매뉴얼, 새 한국 공식 보관 문서·도시 지도 원문 위치와 개별 해시. 새 공식 페이지·첨부의 실제 확보 범위는 연구 JSON과 INPUT_MANIFEST를 따른다.
- 신규 확인: 2001년 보관 공식 고구려 지도 PCX 2개(1451×1451,978×978 픽셀)를 확보·CRC/이미지 확인했다. 받은 부여 ZIP의 CRC 불일치는 FAIL로 보존하고 채택하지 않았다. 픽셀 크기는 게임 격자 치수가 아니다.
- 구분: 원본 `.map` 바이트, 공식 지도 그림, 당시 화면 좌표, 서버 출입/스폰은 다른 자료다. 1.25의 목표시기 일치나 PCX 그림의 편집 가능한 지형·충돌 포함을 전제하지 않는다. 북미 새 MAP613은 포맷 비교용이다.
- 관측 MAP-P15-01: 국내성/부여성 각각에서 공식 자료의 사대문·주요 건물·초보 사냥터 입구를 앵커로 고정하고 지도 좌표계·원점·방향·치수 후보를 대조한다. 도시마다 결과를 기록한다. 셀별 근거가 없으면 좌표를 확정하지 않는다.
- 관측 MAP-P15-02: 실제 선택한 판본의 지형·객체·충돌·가림·출구를 독립 그림/도구와 비교한다. 필수 지도1개 누락·잘린 파일·범위 밖 객체를 거부하고 이전 정상 입력을 보존한다.
- 남은 장애: 한국 목표시기 전체 editable MAP/충돌/서버 출구·NPC·스폰 대응. 해독 준비와 원작 지형 채택을 따로 판정한다.

## P2-02 — 캐릭터·장비·NPC·몬스터 합성

- 입력: 한국491 부품·팔레트·프레임·DrwOrder·MonsFrm 정규화 표, 원본 위치/해시, 고정 도구 소비 코드와 자료 미리보기. 같은 역할의 NPC를 한 외형으로 일괄 매핑하지 않는다.
- 관측 MOT-P15-01: 한 고정 몸/머리/무기 조합을 네 방향에서 정지·걷기·공격·시전으로 비교하고, 각 부품 기준점/offset/레이어/방향을 따로 기록한다. 존재하지 않는 독립 피격·사망 동작을 강제하지 않는다.
- 관측 MOT-P15-02: Body/DrwOrder/MonsFrm/Monster 표의 개수·stride 차이를 각각 확인한다. 다른 세대의 표를 숫자 ID만으로 합치지 않는다. 지연 raw값을 근거 없이 ms로 바꾸지 않는다.
- 관측 MOT-P15-03: 로그인/생성 EPF의 선언 폭과 마스크 행 길이 불일치를 재현하고, 관련 도구의 stencil 처리와 원본 렌더 결과를 대조한다. 잘라내기·frame0 대체로 통과시키지 않는다. `0x80` 코드 차이는 별도 가설이며 실제 실패 원인 확정과 구분한다.
- 남은 장애: 개별 한국 NPC 이름/시대/지역과 외형의 완전 결합, 모션 의미·속도·전환, 일부 UI 프레임 마스크 해독.

## P2-03 — 기술 효과·소리·명중 시간

- 입력: Effect 시퀀스128, Effect.frm palette 참조, 앞/뒤·반복·Delay/Alpha/Light raw값, WAV163개 개별 ID/PCM·파일 hash·길이·채널·rate, 타권역 기술 호출 비교 표. 수량은 최신 연구 결과와 대조한다.
- 신규 확인: 실제 확보 GIF60건을 전수 비교해 서로 다른 KR491 효과 시퀀스13종과 기술명32개의 그림 관계53건을 식별했다. 예를 들어 공식 그림043은 원본 효과56과 대응한다. 판본·실제 보관 시점·완전 일치/부분 일치·중복 후보를 개별 기록했으며 숫자 ID 일치로 합치지 않았다. 위치·Delay 단위·음향·명중 시점은 이 비교로 확정하지 않는다.
- 관측 FX-P15-01: Frame#=-1 지연/광원 이벤트와 From=-1/To=0 같은 혼합 반복 sentinel의 의미를 확인한다. 음수 인덱스를 배열 마지막 프레임으로 읽지 않는다. 원문 미지원 명령은 명시적으로 거부·보류한다.
- 관측 FX-P15-02: 한국 기술별 입력→동작→명중→피격 표시→효과→실제 소리 출력→다음 행동 허용을 동일 판본·장비·상태에서 관찰한다. 영상 frame time과 녹음 sample time을 함께 기록하고 서버/녹화/오디오 출력 지연을 분리한다. 허용 오차는 관측 해상도와 반복 변동에서 정한다.
- 관측 FX-P15-03: 같은 WAV 내용의 다른 ID를 보존하고 실제 호출별 의미를 확인한다. 한국·NA 같은 숫자, 공통 sound003·고정160ms·뷰어 재생 속도를 원작값으로 채택하지 않는다.
- 남은 장애: 한국 기술→효과→소리 의미 연결·Delay 단위·실제 명중/출력/재행동 시점. `play()` 호출 성공은 청각 PASS가 아니다.

## P2-04 — 로그인·생성·한글

- 입력: 원본 Dlg 계열·한국어 리소스 문자열, 당시 공식 생성 절차/선택 항목 근거, 사용자 사진과 옛 화면, NA 로그인/이름 정책의 코드 위치. 선택지 문자열 존재와 실제 화면 순서는 따로 확인한다.
- 신규 확인: 2001-06-07 보관 공식 생성 화면의 실제 GIF와 명시된 성별/얼굴/나라/신수 제어를 확인했다. 보이는 얼굴4개와 전체 허용 옵션·선택 순서는 다른 사실이며, 실제 한글 생성/IME 동작은 미실행이다.
- 관측 UI-P15-01: 각 선택 단계의 다음/이전/취소/재선택·중복·잘못된 이름·생성 후 초기 상태를 화면과 상태 양쪽으로 기록한다. 평민Lv1·미학습 공격기술 없음·Lv5전직 요구를 유지한다.
- 관측 UI-P15-02: 실제 Windows/Android IME 조합 중 입력, 확정, 지우기, 포커스 전환, 취소, 조합문자 중복 제출을 각각 확인한다. NA ASCII 정규식과 한국 원작 이름 길이/금칙어 정책을 동일시하지 않는다.
- 남은 장애: 한국 원작의 서버측 이름 정책, 실제 플랫폼 입력·생성 UI 동작. 옛 그림·로컬 프로필·실제 인증을 하나의 로그인 PASS로 묶지 않는다.

## P2-05 — 두 플랫폼 입력·UI·로컬 저장

- 입력: 사용자 오른쪽4패널/하단 상태 요구, source provenance, `save_contracts.json`의 좁은 재사용 후보와 원래 코드 hash. 저장 envelope schema2는 참고이며 새 형식으로 자동 채택하지 않는다.
- 관측 SAVE-P15-01: 같은 상태를 실제 Windows EXE와 Android 앱에서 저장/재시작하고 한글·stableID·좌표·장비·기술·바닥 전리품을 비교한다. 실제 Galaxy와 에뮬레이터 결과를 분리한다.
- 관측 SAVE-P15-02: 임시 기록·검증·백업·교체의 중단/쓰기 실패/손상/강제 종료와 업데이트를 사본에서 시험한다. 기존 checksum이 다루지 않는 외부 메타데이터와 소유자/지도/ID 범위도 검증한다.
- 관측 SAVE-P15-03: 지도 버전만 변경된 경우 유효 좌표는 유지한다. 명시 변환이 없거나 변환 실패면 원본·보류 상태를 보존한다. 캐릭터/전리품의 일괄 입구 이동·삭제·임의 가방 지급은 금지한다.
- 현재 환경: Linux 정적 처리 환경. Windows/Galaxy/앱 서명/실제 사용자 세이브는 실행하지 않았다. 도구 미연결·권한 부족·미시도를 동일하게 적지 않는다.

## P2-06 — 같은 계정 순차 이어하기

- 입력: 기존 CAS/revision·lease·offline journal·conflict 보존 코드와 명세. 참고 코드 읽기만 수행했으며 인증 서비스 호출/DB 변경/배포는 하지 않았다.
- 관측 SYNC-P15-01: 별도 허용된 무료 실제 인증 경로에서 동일 계정의 PC행동A→Android확인/행동B→PC확인을 수행한다. 온라인 인증·전송과 오프라인 저장은 다른 결과로 기록한다.
- 관측 SYNC-P15-02: 오래된 revision·서로 다른 오프라인 변경·계정 전환·네트워크 단절·전송 취소·재전송에서 덮어쓰기와 이중 적용을 방지하고 양쪽 충돌본을 보존한다.
- 남은 장애: 실제 무료 인증 환경·HTTPS·스키마/권한·실제 기기 접근. 로컬 파일 복사 성공으로 이 단위를 PASS 처리하지 않는다.

## 착수 상태와 종료 의미

각 단위의 최종 준비 상태는 REPORT/STATE에 기록한다. P1.5 바이트 검사와 인계 디렉터리 재읽기는 정적 입력 검증이다. 게임/원작 일치/실제 기기/인증 왕복은 모두 NOT_RUN이다. 중요한 한국 지형·효과/음향·생성/저장 의미가 미확정인 상태에서 P3 전체 게임이나 대량 생성으로 넘어가지 않는다. 새 원문 단서가 없으면 미확정을 숨기지 말고 위 정확한 관측 지점에서 재개한다.
