## 잘못된 기본값을 차단한 실제 사례

Effect.tbl에는 `Frame#=-1`이 **17단계** 존재한다. 이를 마지막 프레임/팔레트로 읽는 Python 음수 인덱싱이나 frame0 대체를 하지 않았다. 원래 Delay/Alpha/Light를 보존하고 `unsupported_semantics`로 표시했다. 효과115·118·119·120은 RepeatFrontFrom=-1, RepeatFrontTo=0이다. 반복 비활성 의미를 임의 확정하지 않고 두 값을 독립 보존했다.

EffRange는0번을 dummy라고 명시하지만 Effect.tbl0번은12단계가 있는 실제 시퀀스다. 따라서 같은 숫자라는 이유로 두 표를 합치지 않았다. EffLayer2의 front2/back6 역시 Effect.tbl2의 front10/back0과 동의어라고 취급하지 않았다. 한국·북미 ID 결합도 하지 않았다.

Delay는 실제 원본 수치 그대로다. 단위를 ms로 선언하지 않았다. Alpha/Light의 수치 존재와 실제 혼합·조명 함수의 의미도 분리했다. Body0의94번은 소스의 빈 프레임이며 임의 그림을 채우지 않았다.

## 로그인 마스크의 실제 미해결

`DLGLOGIN.epf`0번은 너비316인데 스텐실 런 길이 합이187행 모두318이다. `DLGNEW01.epf`0번도 너비316인데202행 모두318이다. 기존 엄격 해독기가 거부하는 사실을 실제 바이트에서 재현했다. 이를 자동 자르기·투명 그림·정상 파일이라고 숨기지 않았다. 원본 파일 손상인지, 구식 UI 전용 관례인지, 다른 소비 방식인지는 **미확정**이다. `DLGNEW02.epf`의 마스크는 해독됐다.

관련 도구의 `0x80` 처리와 기존 파서의 차이도 코드상 발견했으나, 이것을 이번 실제 거부 원인이라고 보고하지 않는다. 현재 인스펙터에 현대 도구의 규칙을 강제 이식하지 않았다. 실패2개는 결과와 종료 코드2까지 전파한다. 나머지 표·프레임 산출물은 보존한다.

마스크가 막힌 두 UI의 미리보기는 **원본 픽셀 인덱스만** 사용했다. 팔레트는 파일명 대응 후보이고, 실제 색 일치는 미검증이다. 화면이 거칠거나 푸른 미리보기를 옛 게임의 올바른 UI 색이라고 채택하지 않았다.

## 한국어 생성·UI에서 확인한 것

Str_Kor에는 성별·얼굴·국가·수호동물 선택 안내와 암호 확인·생년월일 오류·한글 상태 설명이 실제 존재한다. 생성 안내가 국가를 고구려·부여 두 가지라고 명시하는 한편, 독립된 오래된 `신라인` 문자열도 남아 있다. 문자열 하나의 존재를 기본 생성 국적 허용으로 삼지 않는다. 선택 순서, 초기 평민/장비/위치, 이름 길이·중복 규칙은 해당 서버/화면 동작 근거가 더 필요하다. 원본 UI 문장을 NPC 원문 대사로 분류하지 않았다.

공식 안내서 담당이 확보한 효과 그림의52개 논리 상대 경로를 대상으로64 URL 요청을 수행했고, 이 중60개 응답의 실제 GIF(고유 바이트51개)를 **모두** 이번에 비교했다. 3개 접근 실패와1개 비이미지 응답은 그림 부재로 처리하지 않는다. 서로 다른 URL·시점이 같은 바이트를 반환하면 고유 그림 수에 중복 계산하지 않았다.
