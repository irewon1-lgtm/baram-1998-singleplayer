# P3 착수 판단: BLOCKED / 이번 실행에서 시작하지 않음

Work 담당을 유지한다. 별도 Codex 세션으로 자동 전환하지 않는다. 이번 종료점은 원본 기반 G0·P2의 실제 부분 결과다.

현재 재사용 가능한 기반은 동일 Godot 검수 프로젝트, 한국1.25 지도3개의 원본 타일·정적객체 렌더, 원본 EXE 정적 이동규칙, 한국4.91 부품 합성·유효 생성UI·효과 프레임/오디오 믹서 소비, 보존한 Codex 저장 모듈이다. 원본 픽셀 성공이 목표시기 지도나 규칙의 확정은 아니다.

작은 처음~사냥~저장 구간을 원작복원으로 착수하기 전에 다음이 필요하다.

1. 2000/2001 후보 중 기본 프로필 하나를 근거로 선택한다. 한국1.25 지도 ID를 목표시기 국내성·부여성으로 확정하지 않는다. 도시/사냥터 앵커와 실제 출구·귀환 목적지·활성 경계를 확인한다.
2. 같은 판본의 캐릭터와 정적객체 사이 실제 이동·가림을 검증한다. 이번 지도에는 캐릭터 보행을 연결하지 않았다. 저장격자 충돌 판정과 실제 보행·서버 활성범위는 다르다.
3. 원본 부품의 방향·모션·토큰 의미를 시각추론에서 독립 근거로 보강한다. 마스크3건의 run 폭 불일치 원인을 해결하고 원본·실패를 보존한다.
4. 효과의 뒤 레이어·반복·Alpha/Light/sentinel 의미, 대표 기술의 효과·소리·타격/재행동 시점을 확인한다. 이번 안전 프레임 미리보기와 WAV 별도 재생을 전투기술 구현으로 세지 않는다.
5. 원본 생성UI의 실제 선택·취소·재선택 흐름과 한글 IME를 연결한다. 평민Lv1·희망직업과 실제직업·미학습 공격기술0은 공유 검수 상태에 보존한다.
6. 네이티브 Windows의 기존 시험 환경에서 Work 브랜치가 허용되면 같은 원본 프로젝트와 보안 assertion을 실행한다. 기존 Wine12 FAIL과 환경 branch rule 차단을 유지한다. Galaxy/실제IME는 연결 환경이 있어야 시험할 수 있다.

인증은 P2-06만 BLOCKED다. 무료 시험용 인증·HTTPS·DB endpoint가 확보되어도 사용자 운영DB·실제세이브는 쓰지 않는다. 오프라인 저장과 소스 개발을 함께 멈출 이유는 아니나, 같은 계정 PC→Android→PC 인증 왕복 완료로 보고하지 않는다.

다음 재개는 STATE_WORK_P2.json → INPUT_MANIFEST.json → RESULTS.md → 실제 원격HEAD·전달 영수증 순서다. 같은 SHA·같은 조건의 P1.5 전체 조사/해독·동일 합성 저장 회귀를 반복하지 않는다. 새 입력 세대를 시험 경계에서 만들고 영향 범위만 실행한다.
