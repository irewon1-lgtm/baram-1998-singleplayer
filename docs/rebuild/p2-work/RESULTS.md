## 실제 소비와 재사용

LIB-009 한국1.25 ZIP의 MAP·DAT·WINDLAND.PAL·정적객체를 kr125_map.py가 변환하고 기존 검수 프로젝트가 렌더했다. LIB-010 한국4.91 ZIP의 NWind.dat/snd에서 몸·머리·검·방패·Effect·WAV·유효 UI를 연결했다. LIB-018 아틀라스는 확인했으나 판본이 다른 타일을 섞지 않기 위해 미사용이다. 원본ID→코드→관측 연결은 SOURCE_USAGE.jsonl에 있다.

Codex의 프로젝트 구조, 저장 모듈, native USERDATA 파일 API, 고유 시험 저장 경로, checksum/소유자/백업/지도 이전 보호를 재사용했다. 기존 저장·참조 서버·수신 도구의 같은 조건 합성시험은 새 실행으로 재계산하지 않았다. 이번 Linux 최소 확인은 UI11/저장85, 원본 영향 검수는 최종47이다. Android 과거 Codex85와 이번 원본 검수도 별도다.

B001/B002 실제159후보와 원문·정규화 레코드를 검증했다. 혼합5형식 어댑터를 만들고6개 후보를 검수 제약으로만 사용했다. 데이터패치0,159기능 완료 아님. NA154 참조 FAIL과 기존 Codex DEFERRED는 역사 기록으로 보존했다.

## 수정한 결함과 보존한 실패

- 생성 화면 노이즈는 잘못 추론한 DlgLogin.pal 연결이 원인이었다. 원본EXE 생성자/그리기 경로의 정적 근거에 맞춰 BARAM.PAL로 정정하고 GEN002와 GEN003을 분리했다.
- 로그가 재사용 배열을 참조해 과거 화면 경로가 뒤바뀌던 결함을 깊은 복사로 수정했다. 실제 PNG는 보존했고 새 실행에서 경로 추적을 확인했다.
- DLGLOGIN/DLGNEW01/DLGPASS 마스크는 프레임폭과 run폭이 불일치한다. 원인 미확정이며 잘라내기·빈그림·frame0 대체·전역FF 규칙 변경을 하지 않았다.
- Windows 시험 환경의 branch 보호 거부는 실행 전 차단이다. 보호 규칙과 보안 assertion은 변경하지 않았다. 에뮬레이터 stale lock과 TCG/ADB 초기 실패도 새 영수증으로 보존했다.

## 복원과 다음 재개

Work 통합 브랜치는 work/rebuild-runtime-20261016이다. GEN003 코드와 입력을 깨끗한 별도 디렉터리에서 복원해47검사·저장 checksum 일치를 확인했다. 같은 서비스/계정 내 재현이며 다른 도구/사용자의 수신 검증은 아니다. 지속 입력 경로와 실제 저장ID·해시는 INPUT_MANIFEST/PRIVATE_DELIVERY/RESTORE.md를 따른다. 현재 상태는 STATE_WORK_P2.json에만 갱신하고 공통STATE·계획·game·Codex 이력·Work 발행배치는 건드리지 않았다.

시험 앱은 원본 자산 검수용이다. Android는 자동 검수 후 종료한다. 실제 게임 플레이/업데이트본이 아니다. 기존 앱·사용자 세이브·기존 서명키를 쓰지 않으며 새 패키지/저장 경로를 사용한다. Windows는 압축 해제 후 EXE를 열 수 있으나 네이티브 실행은 미검증이다.
