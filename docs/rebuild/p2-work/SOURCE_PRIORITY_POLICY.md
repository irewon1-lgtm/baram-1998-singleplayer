# 한국판 바람의나라 자료 채택 우선순위 — v1 (2026-10-16)

## 목적과 적용 범위
- 적용 프로젝트: 개인용 한국판 1998~2001 바람의나라 재구축.
- 사용자가 승인한 결정: **겹치는 자료는 한국 넥슨 공식 자료를 최우선으로 하여 아래 순서로 하나를 선택하고, 서로 다른 값을 기계적으로 평균 내지 않는다.** 공신력 순위는 게임 데이터를 선택하는 절차이며 원본 삭제·파일/세이브 변조·런타임 시험 PASS를 허용하지 않는다.
- 기존 AGENTS.md, docs/rebuild/MASTER_PLAN.md의 원본 보존·시대/지역 구분·안전 실행·실제 시험 분리와 병행한다.
- 기존 P1.5 원장·Work B001/B002·GEN003 입력·비공개 원본은 읽기 전용이며, 이 파일 자체는 선택 규칙을 기록할 뿐 기존 게임 데이터의 선택·적용·시험을 수행하지 않는다.

## 0. 적용 적격성: 순위보다 먼저
1. 대상 필드·개체·지역·직업·일반종/보스·서버/클라이언트 책임과 복원 목표시기를 결정한다. 사용자가 지정한 화면 배치·조작 요구는 UI 설계의 별도 필수 조건이다.
2. 해당 출처의 한국/북미, 자료가 **묘사하는 게임 버전과 시기**, 캡처/작성/보관 날짜, 원문 여부, 해독 상태를 구분한다. 보관일이 2001년이라고 2001년 내용이라는 증거가 되지 않는다.
3. 목표 연도에 존재하지 않았던 기능·수치나 지역이 다른 데이터는 한국 원작 **직접 근거로는 부적격**이다. 보조 참고로 보존할 수 있다. 후대의 넥슨 공식 글도 목표 시대와 다르면 같은 규칙을 적용한다.
4. 그림·모션은 당시 실제 한국 클라이언트/영상이 직접 증거이며, 드롭률·NPC 서버 대사 등은 클라이언트 그림만으로 확정할 수 없다. 필드의 관측 가능성과 출처의 구체성을 함께 평가한다.

## 1. 적격 후보 간 기본 우선순위
| 순위 | 출처 부류 | 적용 방식 |
|---|---|---|
| **1** | **한국 넥슨 공식 원본**: 목표시기 KR 클라이언트 내 해당 자료, 넥슨 당시 공지·공식 사이트·게임 도움말·공식 화면/음향/표 | 같은 항목·시기·필드의 직접 근거를 최우선 채택. 단 클라이언트에 없는 서버측 확률을 단정하지 않음 |
| **2** | **한국 동시대 기록**: 당시 한국 플레이어 커뮤니티의 원본 화면·영상·경험기록, 당시 국내 가이드북·게임잡지·CD 부록과 실측 공략 | 공식 근거가 해당 필드에 없거나 목표 판본에 맞지 않으면 직접성·동시대성을 확인하여 채택 |
| **3** | **국내 검색·후대 한국 자료**: 국내 팬카페/블로그/아카이브·복원 연구·재인용 공략 | 원문 이미지나 날짜·출처를 가진 것이 우선. 단 검색엔진은 발견 경로이지 출처 등급이 아님. 검색으로 발견한 넥슨 원문은 1순위, 당시 커뮤니티 원문은 2순위로 분류 |
| **4** | **해외 GitHub/오픈소스**: Project1998, RTK 등 실제 코드·고정 버전·데이터와 포맷/프로토콜 구현 | 한국 자료가 없는 구현 원리·바이너리 포맷·행동 후보의 참고. 북미 서버의 NPC·맵·확률·직업 조건을 한국판 정답으로 자동 이식 금지 |

| **7** | **근거 기반 재구성·추정**: 당시 한국판의 가장 가까운 지형·NPC·동작·수치를 조합한 작업용 값 | 상위 출처에 직접 값이 없고 정상 플레이에 필요할 때 선택. `RECONSTRUCTED` 또는 `BALANCE_ESTIMATE`로 명시하고 교체 가능하게 유지 |

## 2. 충돌·누락 해소 알고리즘
1. 필드 단위로 모든 후보를 모으고, 원본 ID/위치·시기·판본·출처 계보를 보존한다.
2. 대상 프로필에 적격인 후보만 먼저 거른 뒤 1→7순위로 탐색한다.
3. 같은 순위에서 충돌 시: **정확히 해당 게임 버전·지역·직업** → 원문 또는 직접 화면/실측 → 더 명확한 전체 문맥·변경 날짜 → 독립 검증 순으로 선택한다.
4. 선택된 값 하나를 **작업용 프로필의 활성 후보**로 정한다. 다른 값은 삭제하지 않고 VARIANT/CONFLICT 목록에 남긴다. 역사적 확정 여부는 별도 필드로 유지한다.
5. 낮은 순위만 존재하면 그 값을 해당 등급의 후보로 채택하여 구현을 진행할 수 있다. 최상위 근거가 없다는 이유만으로 영구적으로 빈값으로 만들지 않는다.
6. 범주/코드/타일/프레임/아이템/기술/음향 ID, 좌표, 레시피 구성은 **절대 평균 내지 않는다**. 근거가 맞는 한 판본을 선택한다.
7. 수치(가격/경험치/공격력/기술 소모 등)도 **충돌 후보 간 평균은 기본 금지**다. 선택 판본의 한 값을 우선한다. 불완전한 같은 조건의 관측치나 단일 값이 아예 없을 때만 보간·합리적 균형값을 `RECONSTRUCTED`로 별도 명시할 수 있다.
8. 드롭/제작 확률은 퍼센트·가중치·독립추첨·배타추첨을 먼저 판별한다. 정보가 없으면 `BALANCE_ESTIMATE`로 게임에 넣고 시드 고정·대량 반복·경제 밸런스 검사한다. 공식 확률이라고 표기하지 않는다.
9. 맵 출구·충돌·아이템 소유권·저장 좌표·무한 애니메이션 같은 **기술적 안정성**은 출처 등급과 관계없이 검사를 통과해야 한다. 불확실한 효과 라이트/모션 시간은 안전한 제한된 대체를 사용하되 `RECONSTRUCTED`와 화면·성능 시험 기록을 남긴다.
10. 확정 자료가 추후 발견되면 기존 작업용 값을 버전별 대체하고, 영향받는 시험만 재실행한다. 기존 세이브/원본 변경·무단 좌표 이동·파손은 금지한다.

## 3. 복원 프로필과 구분해야 할 판정
- 사용자의 목표는 **한국 1998~2001**이며 다른 시기의 값들을 무작위 혼합하지 않는다. 현재 GEN003 검수의 판본 미선택 상태와 역사적 논쟁 기록을 유지할 수 있으나, 실제 플레이 가능한 시험 프로필은 목표시기 내 **일관된 한국판 기준 연도/판본을 명시하여** 선택할 수 있다. `null`이어야만 테스트 PASS라는 조건을 원작 정확성/작업 진행 차단으로 오용하지 않는다.
- 상태는 적어도 `ORIGINAL_VERIFIED / CORROBORATED / RECONSTRUCTED / BALANCE_ESTIMATE / UNKNOWN`로 구분한다.
- 이용 상태 `ACQUIRED / DECODED / IDENTIFIED / SELECTED / BOUND / EXERCISED`와 시험 `PASS / FAIL / NOT_RUN / BLOCKED`는 각각 별도 기록한다.
- `SELECTED`나 `RECONSTRUCTED`는 게임에서 그려지고 소리 난다는 증거가 아니다. 실제 게임 소비·시청각 검증 뒤에만 `EXERCISED`로 기록한다.
