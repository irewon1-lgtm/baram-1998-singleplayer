# 리소스 권리 정책

넥슨 공식 '게임 IP 사용 가이드'는 게임 IP를 활용하여 게임을 제작하고 배포·서비스하는 것을 원칙적으로 허용하지 않는다고 설명한다. 출처: https://member.nexon.com/policy/gameipguide.aspx .

- **개인용 오프라인 복원을 목적으로 하지만 원본 리소스의 이용 허가 여부는 별도 근거로만 판단한다.** 저작권·복제·개작과 배포의 법률적 영역은 별도로 검토해야 한다.
- 현재 GitHub 저장소는 공개로 운영한다. 공개 저장소에는 직접 제작한 코드·연구·출처 링크만 보관한다. 완성 게임의 외부 배포는 범위 밖이다.
- 원본 게임 파일·클라이언트·추출 스프라이트·음원·유료 가이드 스캔 전문을 GitHub에 올리지 않는다.
- 원작 인터페이스를 연구할 때에는 원문 위치/링크·기술 분석값·자체 제작 비교 결과를 기록하고, 복제 이미지 파일은 별도로 허가받기 전 저장소에 넣지 않는다.
- 직접 그린 신규 픽셀 아트·직접 만든 음향·오픈 라이선스 자료도 저작권/라이선스를 추적한다.
- Godot 게임 엔진은 MIT 라이선스(https://godotengine.org/license/)이나 넥슨 원작 콘텐츠의 사용 권한까지 부여하지 않는다.
- 정확히 같은 그래픽·음악까지 요구한다면 우선 **권리자 허가/자료 이용 계약**을 알아봐야 하며, 허가 없으면 독자 아트의 **고증 분위기 재현**이 현실적 대안이다.

`research/ASSET_LICENSE_MANIFEST.csv`에서 리소스별 사용 허가를 반드시 기록한다.
