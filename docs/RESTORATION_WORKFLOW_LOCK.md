`research/korean-history-20261013/extracted-candidates.jsonl`의 모든 ID에 대조 결과·이유·근거 위치를 기록한다. 검증 성공, 중복, 오류, 자료 부족, 검증 보류를 서로 배타적으로 집계한다. 출처 표를 읽었는지, 기존 확인 원장과 연결했는지, 실제 게임 적용을 확인했는지 구분한다. 미검증 1,674행을 1,674개 고유 콘텐츠라고 부르지 않는다.

## 4~5단계 입력과 실행 상태

에셋은 버전·파일·해시·형식·팔레트·프레임·방향·동작·내용·권리를 연결한다. 확보 파일, 해독된 그림, 식별된 개체, 동작 연결을 별도로 센다. 해시로 중복을 제거하며 렌더링을 실행하지 않았으면 `NOT_RUN`이다.

기능 원장은 자료 확보 / 코드 존재 / 게임 구현 / 자동시험 / 실제 화면 조작 검증을 독립적으로 기록한다. 서버 코드가 있어도 이 게임의 구현 완료가 아니다.

`BALANCE_TESTS`는 경험치·레벨업·장비·기술·피해·드롭·상점·수리·4직업 성장 시험 입력과 기대 조건이다. 실제 게임 계산 코드와 동일 코드로 실행하기 전 시뮬레이션 PASS를 주장하지 않는다.

## 공개 범위와 검증

권리 미확인 외부 코드·원작 이미지·음향·클라이언트 바이트는 공개 저장소에 복사하지 않는다. 주소·해시·사실·독자 작성 데이터 변환과 검증 도구를 기록한다. 외부 소스 분석용 사본은 저장소 밖에서 취급한다. 유료 작업·운영 배포·main 병합은 사전 승인 없이 하지 않는다.

실제 검사에는 시간·대상 SHA/입력 해시·명령·기대값·관측값·종료코드·로그를 남긴다. 형식·중복·출처·단위·개체 연결 검사를 실제 실행한다. `PASS`는 실행 근거가 있는 해당 범위만, `FAIL`은 기준 불충족, `BLOCKED`는 접근/자료/환경 장벽, `NOT_RUN`은 미실행이다. 일부 검사 PASS를 전체 준비·게임·원작 완전 재현 PASS로 확대하지 않는다.
