비영사천문 목적지 탐색의 전역 순회와 같은 맵 타일 캐시 재생성 제거는 **PASS**다. 처음 보는 Work 맵의 첫 그리기 약 **340ms**, 동기 저장 약 **717ms** 지연은 남아 있어 전체 성능 복구는 **FAIL**로 기록한다. Android 플레이어 APK의 처리 프레임 간격은 추가 측정에서 **FAIL**이며, 별도 GPU 제시 FPS·Windows FPS·첫 조작 가능 프레임은 **NOT_RUN**이다.

## 실행 범위와 동일성

- Linux / Godot 4.6.3 / X11 / 소프트웨어 OpenGL `gl_compatibility`에서 실행했다. 지도 423개, 몬스터 인스턴스 4,578개, 시작 마을 220×220칸의 실제 통합 데이터를 사용했다.
- 맵 전환 측정은 별도 계측 서브클래스가 실제 `main.gd`의 `transition()` 및 `super._draw()`를 호출했다. 정상 생성한 독립 평민 캐릭터의 별도 저장 경로를 사용했다. 단계별 비용을 분리하는 직접 호출이며 정상 입력 경로 플레이의 대체 증거로 쓰지 않는다.
- 측정 프로젝트는 동결된 `f0247ced8ed62313af5c6b506533d1295e497a52` APK 빌드 프로젝트, 콘텐츠 `e43e30ccea064113c22ae8a28a3675348a283b05b6775121df1ba5ebb901465b`다. 현재 `243448ac891232cc879a9321c9320133a4ae8020`의 운영 GDScript 21개와 **원문 바이트 전부 동일**함을 확인했다. Android 프로젝트 설정과 검증 스크립트는 이 동일성 범위에서 제외했다. 최신 네이티브 CI 설치본을 실행했다는 뜻이 아니다.
- 운영 코드·설치본·기존 세이브·원본 자료를 수정하지 않았다. 첫 그리기 단계는 각 조건 1회이므로 여러 기기/여러 맵의 성능 분포를 대표하지 않는다. 공개 자료에는 원본 그래픽을 복사하지 않았다.
