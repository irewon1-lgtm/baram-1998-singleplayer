# 현재 실행 검증 상태

복구 브랜치가 게시되었고 게임·원본 자산·콘텐츠·세이브를 새 게임으로 교체하지 않았다. 원문 파일54개와 설치본에서 회수한 메인 코드의 토큰 동등성을 대조했다. 검증 도우미2개는 실제 시험에서 발견된 입력 경로를 보강했다.

| 항목 | 결과 | 실제 범위 |
|---|---|---|

비영사천문 실제 시전의 탐색은 후보1·전체 엔티티 방문0·경로 탐색0·20µs였다. 이는 기기 전체 프레임 시간 보증이 아니다. 저장 스냅샷·커밋에서 약717ms가 관측되어 무정지 성능 완료를 주장하지 않는다. 기존 원본 미확보 자산9개와 공격 모션 부재4모델 등의 한계도 유지한다.

## 원격 실행 차단

[실패한 원격 실행](https://github.com/irewon1-lgtm/baram-1998-singleplayer/actions/runs/38724985965)의 실제 오류는 다음과 같다.

> Branch "work/gameplay-recovery-20261015" is not allowed to deploy to baram-windows-private due to environment protection rules.

결제 차단이나 게임 실행 오류가 아니다. 보호 설정을 임의로 변경하거나 다른 허용 브랜치로 우회하지 않았다. [GitHub 환경 설정](https://github.com/irewon1-lgtm/baram-1998-singleplayer/settings/environments)에서 기존 보호 규칙을 유지하며 `baram-windows-private`에 이 정확한 브랜치 하나를 허용할 승인이 필요하다.

승인 후 보강한 최신 소스로 새 네이티브 실행을 요청해야 한다. 이전 `f0247ced` 실행을 그대로 재시도하면 보강 전 시험 도우미가 실행된다. 게시 체크포인트의 `[skip ci]`는 이미 원인이 확정된 보호 차단을 반복 요청하지 않기 위한 것이다. 환경 승인 후 워크플로의 실행 표기를 갱신해 최신 HEAD로 실행한다.

Android·Windows 실제 OS 필수 검사와 소스·콘텐츠·서명·저장 호환성 대조가 모두 통과하기 전에는 최종 설치본 완료로 판정하지 않는다.
