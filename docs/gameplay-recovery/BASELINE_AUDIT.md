## 검사 방법과 한계

`audit/export_runtime_world.gd`는 엔진의 실제 ContentRegistry로 world를 읽고 픽셀/전체 타일을 제외한 감사 입력을 만든다. `audit/audit_runtime.py`는 다음을 독립 검사한다.

1. 제작 패키지001~010의 모든 manifest 파일 크기·SHA 및 실제 활성 import 정체.
2. 방향별 충돌 마스크·고정 NPC 충돌을 반영한 지형 BFS.
3. 걷기/상호작용 출입구와 실제 NPC 여행 목적지를 포함한 전역 경로.
4. 지역 내 출입구·NPC 상호작용 위치·몬스터 공격 인접 위치의 접근성.
5. 몬스터 배치·교관·퀘스트·제작법·상점 및 아이템 획득 경로 참조.

몬스터 이동·동시 점유·실제 터치·공격·효과·자연 육성·모든 퀘스트 완주는 정적 BFS로 검증할 수 없다. JSON의 모든 개별 지도 `whole_map_playthrough`는 NOT_RUN이다. 예전 controlled 시스템 시험이나 파일 해시를 이 범위의 실제 플레이 PASS로 바꾸지 않는다.

기계 판독 정본: `baseline-static-audit.json`. 수정본의 동일 검사는 다른 파일로 기록해 이 기준을 보존한다.
