# 1998 원작 증거 판정 정책

## 각 값에 반드시 기록할 데이터

`record_id, subject_id, field, value, unit, target_version, applicable_from, applicable_until, source_id, source_publication_date, locator (잡지/페이지/URL/영상 타임코드/파일 SHA256), extraction_method, reviewer, verification_status, contradictions`.

**정확한 값으로 확정**할 조건: 당대 1998년 원본 또는 시점이 입증된 자료에서 수치를 식별하고, 그 값이 대상 기간에 적용됨을 확인; 다른 출처와 충돌하면 판정 중단. 복원 소스 코드·원본 데이터베이스가 확보될 경우 권리·버전도 별도로 검증한다.

## 상태 구분

- `CONFIRMED_OFFICIAL`: 공식 연혁이 보증하는 *내용의 존재 연도*까지만 확정 (공격력 수치까지 자동 확정 아님).
- `CONFIRMED_CONTEMPORANEOUS`: 1998 당대 1차 사료 및 유효 버전이 확인된 사실 또는 값.
- `SUPPORTED_RETROSPECTIVE`: 후대 신뢰 가능한 보도, 당대 원본 미확보.
- `PROVISIONAL_SECONDARY`: 후대 팬 사이트, 전언.
- `UNVERIFIED_1998`: 정확한 버전/수치 미확인.
- `CONTRADICTED`: 자료 충돌, 보류.
- `EXCLUDED_POST_1998`: 1999년 이후 확인된 콘텐츠.
- `ASSUMED_GAMEPLAY`: 시제품용 임시값. 확정 원장과 물리적으로 분리.

## 반드시 막아야 하는 오염

- 2024~2026 '바람의나라 클래식' 수치를 1998 수치로 그대로 복사.
- 1996 박물관 복원 화면을 1998 4.0 화면이라고 주장.
- 촬영·게시 시기 불명인 스크린샷을 1998-12로 단정.
- 팬 페이지 3개가 같은 문구를 복사한 경우 '독립 3개 근거'로 계산.
- 1999년 후대 추가 아이템/마법/2차 승급을 1998 엄격 모드에 포함.

## 화면 복원 증거 등록

출처 이미지 원본을 무단 업로드하지 않는다. 기록할 것: 공개 URL, 출처·촬영일 검증 상태, 이미지 해상도(확정 시), 패널 경계/타일 크기(계측 시), UI 색상/글꼴 후보, 비교용 자체 제작 테스트 화면과 측정값. 사용 허가를 확보하면 별도 관리.
