**엄격 원작 모드**는 1998 적용 사실이 입증된 항목만 채택한다. **테스트 모드**는 구현 검증을 위한 임시 숫자·임시 그래픽을 허용하되 별도 경로로 분리한다. 임시값을 원본으로 위장하지 않는다.

**싱글플레이 변환**: 원작이 다인원 플레이를 전제하는 퀘스트·사냥 방식은 임의로 수정하지 않는다. 실제로 혼자서 진행할 수 없을 때만 별도 SOLO_ASSIST 선택 모드에서 NPC 동행/난이도 보조를 제안하고 원작 엄격 모드 기록과 구별한다.
