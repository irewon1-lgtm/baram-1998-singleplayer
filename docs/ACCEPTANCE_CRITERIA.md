# CLEAN PASS 기준 — 기능 구현과 원작 일치도를 분리

| 검증 축 | 기능 PASS의 최소 요건 | '1998 원작 일치 PASS' 요건 |
|---|---|---|
| 윈도우 실행 | 실제 Windows 실행/오프라인 정상 기동 | 당시 기기/해상도/모드 판본 대조 |
| 화면 | 자체 제작 임시 UI 표시·충돌 없음 | 1998-12 4.0 판본이 확인된 자료로 픽셀/레이아웃 대조 |
| 이동 | 키 입력·충돌·공격/이동 전환 테스트 | 원작 이동 틱·입력 지연·방향·히트박스 계측 |
| 몬스터 | 스폰·이동·공격·죽음·재생성 자동 테스트 | 해당 1998 몬스터 AI/속도/체력/경험치 증거로 비교 |
| 성장 | 1~99 XP 증가·레벨 처리·저장 복구 | 1998 레벨별 정확 XP 값과 공식 대비 |
| 직업·마법 | 4직업 스킬 적용 및 피해량 결정성 | 원작 마법 해금/대미지/MP 등 자료 대비 |
| 아이템·경제 | 장비·획득·드롭·상점 계산 | 1998 드롭률·장비 능력치·금전 흐름 대비 |
| 1차 승급 | 재현한 승급 규칙으로 엔딩까지 진행 | 당시 체마/퀘스트/승급 NPC 조건 증명 |

- `PASS`: 실제 실행 로그 또는 판본이 확정된 증거가 존재한다.
- `FAIL`: 테스트를 실행했으나 기대와 불일치.
- `BLOCKED`: 자료/권한/기기 부재로 검사 불가.
- `UNVERIFIED`: 아직 검사하지 않음.
- 누락된 증거를 임의 추정치나 사용자 기억만으로 대신하지 않는다.
- 완료율 = `PASS / (PASS + FAIL + BLOCKED + UNVERIFIED)`와 별도로 **검증 가능 분모**와 역사 자료 확보율 표시. 사전 분모 없으면 % 작성 금지.
- 버전 별 회귀: 과거 PASS가 현 브랜치에서 재실행되지 않았으면 '최신 PASS' 주장 금지.

### 자동 시험 필요 사례

- 연속 10회 저장/불러오기 후 레벨·HP·금전·위치·아이템 일치.
- 고정 난수 시드의 타격/드롭 결과 재현.
- 초당 입력, 벽 충돌, 포탈 경계, 사망 직후 저장.
- 4직업 레벨 1→99 경험치 처리 및 overflow 검사.
- 1차 승급 후 이전 세이브와 승급 후 세이브 호환성.

**현 상태:** 게임 코드가 없으므로 위 실제 플레이/게임 기능 테스트는 전부 `UNVERIFIED`.
