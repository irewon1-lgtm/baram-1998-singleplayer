## 수정한 결함

첫 실제 클릭 뒤 지연된 FocusIn 콜백이 남은 이동 경로를 지우는 결함을 재현했다. 과거 입력은 FocusOut/Pause에서만 정리하고 FocusIn에서 새 경로를 지우지 않도록 최소 수정했다. 같은 OS 입력으로 (9,6)까지 도착했다. 이전 실패 로그도 근거 묶음에 보존했다.

Android SDK 설치물의 build-tools 안에 `android-15` 폴더가 한 단계 중첩되어 apksigner 탐지가 실패했다. 작업 전용 SDK 내부 파일 배치를 정리했고 동일 내보내기를 성공시켰다. 원본 게임 데이터는 수정하지 않았다.

저장시험 초기의 백업 기대 좌표 (3,5)는 시험 오류였다. `before_primary_replace` 단계는 최신 정상 primary (4,5)를 이미 backup으로 보존한다. 기대값을 (4,5)로 정정했고 새 격리 fixture에서 재실행했다. 구현/판정 기준을 낮추지 않았으며 첫 실패 결과도 보존했다.

## 화면·데이터의 정확한 범위

지도 원본 FILE 바이트·차원·word·SObj ID·워프 102행을 보존했다. 그래픽은 원본 4.95 세계 + 공식 5.33 Tile.dat의 명시적 매핑이다. 4.x의 방향 충돌을 사용하고 5.33의 변경된 충돌이나 오브젝트 삭제 우회는 가져오지 않았다. 한국어 후보는 지도 표시명·토끼 이름 참고만 했고 Windows CP949 패치는 사용하지 않았다. 전체 번역, 원본 Windows 직접 비교, 모든 지도의 플레이 검증을 주장하지 않는다.

P2 앱은 3개 기술검증 장면이다. 원본 기본 공격 **동작**은 표시하지만 피해·경험치·전리품·NPC·상점·퀘스트·출입구 동작은 아직 없다. 장면 선택 버튼은 시험 UI이며 원작 워프를 새로 만든 것이 아니다. 원본의 동적 문·ForceOpen 규칙은 C# 게임 코어를 통합하는 P3 이후 범위다.
