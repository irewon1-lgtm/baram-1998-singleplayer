# 1998년 12월 4.0 바람의나라 싱글플레이 고증 연구 프로젝트

> **현재 단계: 연구 자료 v1 보존 / 실행 가능한 게임 없음 / GitHub 저장소 생성 완료.** 2026-10-13 기준.

목적: 1998년 12월 말 바람의나라 4.0 시기의 플레이 경험을 개인용 오프라인 싱글플레이로 가능한 범위에서 정확하게 재현한다. 제작사 공식 콘텐츠가 아니며, 게임·리소스 배포 권한을 주장하지 않는다.

- 원작 기준일: **1998-12-31**, 4.0 업데이트의 1998-12-08 적용일은 *잠정*.
- 범위: 당시 입문 → 4직업 성장 → 레벨 99 → 1차 승급. 실제 적용 여부를 고증한 뒤 채택한다.
- 제외: 1999년 이후 출시된 2차 승급 및 후대 콘텐츠 (원작 모드).
- 서버 없음: Godot 4.x 2D 앱 + 로컬 저장을 **계획**. 현재 게임 코드/프로토타입 없음.
- 1:1 재현 보증 불가: 그래픽/음악 권한 및 1998 정확한 수치·타이밍이 확보되지 않으면 불가능.
- **원본 수치 확정: 0건.** 현대 클래식 값과 추정치는 절대 `CONFIRMED`로 변환하지 않는다.

## 중요 규칙

1. `research/v1`와 `research/archive` 기존 파일을 삭제·덮어쓰지 않는다.
2. 수치마다 출처 URL/문서의 페이지·이미지·빌드 ID/당시 적용 근거/신뢰도 기록.
3. 테스트하지 않은 항목은 PASS 처리하지 않는다. 판정은 `PASS / FAIL / BLOCKED / UNVERIFIED`.
4. 공개 저장소에는 직접 작성한 연구·코드·검증 도구만 저장한다. 원작 파일·스캔 전문은 올리지 않는다.
5. 외부 유료 서비스, 공개 배포, 운영 웹서버, CI 과금, 메인 병합 전에 승인 받는다.

## 자료 검사

Python 3.10+ 표준 라이브러리로만 실행:

```bash
python tools/validate_research.py
```

이 테스트는 **원장의 형식과 조작 방지 조건만 검증**한다. 게임 재현도나 1998 정확성을 검증하는 것이 아니다.
