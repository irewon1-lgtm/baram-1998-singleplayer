# 세계 자료 확대 조사 · 2026-10-13

**기존 12개 조사에서 확장하여 실제 구버전 설치 파일·지형·그래픽을 확보했고, Project1998 서버의 로컬 생성/로그인/월드 진입/재접속을 실행 검증했다. 완전한 2001년 싱글게임 실플레이는 아직 미검증이다.**

이 브랜치는 `research/community-sources-20261013`의 `9973e7bb25910a1bfaac1775f34dfef104bac82e`에서 분기했다. 기존 research/community-audit는 당시 결과 그대로 보존했다. 그 문서의 SDK/클라이언트 미확보 상태는 이번 후속 결과로 갱신되며, 과거 기록 자체를 덮어쓰지 않는다. main/1998 원장은 수정하지 않는다.

## 발견 규모

고유 프로젝트/도구/문서 계열 **23개**를 목록화했다. 이것은 게임 엔진 23개라는 뜻이 아니다. 기존 19 checkout을 중복 RTK, 지도 편집기 포크, 봇 변형을 합쳐 16계열로 집계하고, Java RTK·CoM·Judge·Baram Map Editor·EPFTool·RuneGard·NemuTK 7계열을 추가했다. NemuTK는 역사적 페이지만 확보했고 소스 다운로드는 실패했다. RuneGard는 런처와 위키만 확보했다. 데이터 아카이브/NexusAtlas는 별도로 집계한다. 전체 정의와 커밋은 unique-projects.json에 있다.

기존 31,098 추적파일 원장에 추가로 **12,731 파일**(새 Java 서버, 두 P1998 포크, 압축 해제 산출물)의 실제 바이트를 읽고 SHA256을 기록했다. 포크/중복/설치 지원파일도 포함된 파일 조사 수이며 순수 콘텐츠 개수가 아니다.

## 미확보/제한

- NemuTK 실제 RAR: 공개 보존 홈페이지에서 정확한 다운로드 경로까지 찾았지만 Wayback404, 해당 CDX 조회 timeout. RaGEZONE의2006 싱글플레이 글은 역사적 실존 근거이며 실행 증거 아님.
- 4.95 전체 설치 디렉터리/DAT 및 실제 Windows 클라이언트 플레이.
- 검증 가능한 한국1998 원본 클라이언트, 한국2001 서버 규칙·몬스터/마법/아이템 원본 DB, 전체 옛 공략집의 합법적 디지털 원문.
- 완전한 악성코드 탐지 결과. 34 PE의 해시/임포트와 C# 정적 위험 패턴을 검사했지만 최신 AV/동적 분석은 미실행. 외부 원작 EXE/미검사 CoM/Java 서버는 실행하지 않았다. 실행한 P1998 관리 코드도 정적검사만으로 무해함을 보증하지 않는다.

## 자료 접근·출처·권리

실제 다운로드 성공과 실패/재시도를 download-attempts.json에 함께 기록했다. 원본은 격리된 작업 폴더에 보관하고 공개 저장소에는 URL/해시/경로/자체 분석/자체 작성 도구만 올린다. 이 작업 환경의 원본 사본은 영구 보관소가 아니므로 필요 시 원장의 URL/해시로 재수집하고, 권리를 확보한 사용자의 별도 개인 보관소에 보관한다.

Project1998 및 대부분 서버는 명시 라이선스 없음: 공개 접근 가능하다는 이유로 소스를 새 public 게임에 복제하지 않는다. 저작자 허가를 받아야 한다. MIT TKMapper/Godot EPFViewer는 저작권/허가 고지 유지로 코드 재사용 후보. GPL TKClassic/ServTK는 GPL 조건 검토 후 별도 선택. 어느 코드 라이선스도 Nexon/KRU 게임 그래픽·지도에 자동 적용되지 않는다. RuneGard 위키 CC-BY-SA는 위키 글의 조건이며 게임 코드 권리 아님.
