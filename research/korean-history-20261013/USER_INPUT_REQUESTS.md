# 사용자가 직접 확보할 원본

## 실제 사람 확인으로 막힌 자료

- 자료: V챔프1999년9월호, 바람의나라 온라인 소개/직업 공략.
- 직접 확인한 주소: https://koreagamemagazinesarchive.org/magazines/31/page/295
- 필요한 범위: 뷰어294~297페이지의 원본 이미지. 도적/직업, 기술 습득 제물, 주막·상점 수치가 있는 구간이다. 뷰어295에서 실제 표시된 문구는 “뷰어 접근 전 사람 확인이 필요합니다.”였다. 사람 확인을 우회하지 않았다.
- 보내주실 형태: 글자·숫자·표가 읽히는 원본 이미지 또는 고해상도 캡처. 가능하면 잡지명/발행월과 인쇄 페이지 하단도 함께 포함한다. OCR텍스트만으로는 숫자를 확정하지 않는다. 뷰어페이지와 인쇄페이지는 아직 같다고 단정하지 않는다.
- 현재 상태: 검색 OCR단서만 있으며 사실원장에 채택0건. 원본을 받으면 표와 숫자를 대조하고1999년프로필을 보강한다.

## 사람 확인 차단과 별개로 내부 원문이 없는 도서

아래 책은 상품 서지와 광고만 열람했다. 책본문 접근이 CAPTCHA로 막혔다고 주장하지 않는다. 구매는 실행하지 않았다. 보유 중이거나 직접 확보하시면 우선 표지·판권·목차와 관련 데이터 표만 제공해도 된다.

- 4.90 주장 판본: https://www.aladin.co.kr/shop/wproduct.aspx?itemid=268104 — ISBN9788985966122,2001-03-03,350쪽. 실제4.90 판권 확인 필요.
- 5.05 공식가이드 주장 판본: https://www.yes24.com/Product/Goods/224863 — ISBN9788985966283,2001-09-30.447/432면 메타데이터와 후속5.13광고448면이 혼재하므로 판권·쇄·목차부터 확인 필요.

필요한 데이터는 지도/포털/NPC표, 몬스터경험치·드롭, 성장표, 직업별마법습득·시전소모, 장비가격·내구도다. 서적 전체 스캔을 공개GitHub에 올리지 않는다. 제공자료는 개인 분석하고 사실값·출처 위치만 저장한다.
