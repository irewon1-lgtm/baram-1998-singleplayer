# Codex 개발 입력 계약

1. 이 작업은 고증 조사다. 게임 구현·배포·main 변경을 포함하지 않는다. 기존 community/world원장과 자료를 보존한다.
2. 사용할 연도와 구간을 먼저 명시한다. `KR-1998.json`은 주로1998년3월잡지다. `KR-2001.json`은 서로 다른2001년캡처·잡지이므로 하나의 패치 전체라고 표시하지 않는다. `KR-1999.json`은 신규 확정기록이 없어서 빈 배열이다.
3. `facts.jsonl`의 `verification_scope=SOURCE_CONTENT_ONLY`는 원문 기재를 확인했다는 뜻이다. 출처에서 얻은 적정레벨은 입장 제한이 아니다. 가격표 금액은 상점 매입/판매 방향이 확인되기 전 `guide_listed_price`로만 사용한다.
4. 마법 `learn_money`, `learn_materials`, `learn_level`과 시전MP/HP, 피해식, 지속시간은 다른 필드다. 같은 이름의 공통/전사/도사 기술을 직업별 키로 나눈다. 자료에 없는 값을0으로 채우지 않는다.
5. NPC `guide_coordinate`는 안내된 도시/시설 위치다. 내부NPC좌표인지 입구좌표인지 미확정이므로 `local_npc_xy`에 복사하지 않는다. 이름이 음역으로 비슷하다고 북미배치·대사를 자동 채택하지 않는다.
6. `extracted-candidates.jsonl`은 자동 추출 검토 큐다. 원문 표와 원본 이미지의 별도검증 후에만 사실원장으로 올린다. 후보합계를 한국원본 개체수로 보고하지 않는다. source-date-deltas의 양쪽 값을 보존한다.
7. `contradictions.json` C05 동귀어진은 실제효과가 해결되기 전 구현값으로 채택하지 않는다. C01의2002용무기표를1998프로필에 넣지 않는다. C10 백호왕800을 임의로800만으로 고치지 않는다.
8. 최소2001전투 구간의 원문 입력은 토끼XP5/다람쥐XP10, 목도·목검숫자, 전사기술 습득표 등에서 선택할 수 있다. 하지만 HP·공격간격·레벨XP표는 미확보다. 임시값이 필요하면 `assumed_dev`같은 별도표로 명시하고 원작일치라고 하지 않는다.
9. 그림은 sources의주소/해시를 개인분석 폴더로 재수집한다. 이 공개디렉터리에 리소스바이트가 있다고 가정하지 않는다. 한국4.91해시는 world-audit/acquired-original-files.json을 정확한SHA로 읽는다. EPF프레임→날짜가있는KR스크린샷→엔티티ID를 대조해야 그래픽일치로 판정한다.
10. 연구용 재개순서:1999V챔프 원본 접근→책판쇄/공개샘플→1998공식/잡지 세부표→국내맵/포털→마법MP/성장표→프레임·사운드. 네트워크실패는 해당URL과오류를남기고 조건변화 없이 반복하지 않는다.

## 파일 읽는 순서

SUMMARY.json → sources.json → KR-선택연도.json → contradictions.json/source-date-deltas.json → code-comparison.json → missing.json.

원문 주소·캡처시각·페이지·표·행을 잃지 않은 채 엔진별 스키마로 변환한다. 모든 변환 결과는 원래fact_id와 연결한다. 게임과 비교하는 시험은 별도로 실행해야 하며 이 연구 검사 결과로 대체하지 않는다.

## 사용자 지정 숫자 평균 정책 (2026-10-13)

사용자는 금액·경험치 등 서로 다른 숫자의 평균을 지시했다. 제작에서 숫자 충돌을 처리할 때 `IMPLEMENTATION_AVERAGES.json`을 사용한다. 다람쥐XP는7.5, 전사 건곤대나이 습득비용은3250전, 전사 대지의기원 도토리 제물은75개다. 같은 개체·직업·필드의 서로 다른 확인값을 각각 한 번씩 평균했다. 소수점은 유지하며 엔진의 반올림은 별도 구현 결정이다.

평균은 사용자 지정 혼합 제작 프로필이며 특정연도 실제 서버 수치가 아니다. 연도별 원문 및 모순 원장은 유지한다. 제물의 종류가 서로 다른 경우 품목을0으로 가정하지 않는다. 동귀어진의 죽음/잔여HP10 충돌은 뜻이 달라 평균하지 않는다.

사람 확인으로 막힌 원본의 요청 목록은 USER_INPUT_REQUESTS.md에 있다.

추가로 원본 잡지에서 변경 전후를 대조한 건곤대나이 습득레벨80/63은71.5, 사각방패AC -20/-3은-11.5로 평균했다. 실제 패치 전후 수치는 해당 fact의 previous/current 필드에 보존했다.
