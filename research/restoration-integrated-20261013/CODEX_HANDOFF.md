# Codex가 시작할 정확한 순서

작업 정본: `docs/RESTORATION_WORKFLOW_LOCK.md`. 이 통합 브랜치에서 별도 개발 브랜치를 만든다. main 및 기존 조사 브랜치를 유지한다. Work의 데이터 검사 PASS를 게임 검증 PASS로 옮기지 않는다.

1. **자료와 초안 인수인계**: `research/restoration-integrated-20261013/REPORT.md`, `NUMERIC_SUMMARY.json`, `VALIDATION.json`, `CONTENT_CATALOG.jsonl`, `NUMERIC_MASTER.jsonl`, `NUMERIC_SOURCES.jsonl`, `PRODUCTION_ASSUMPTIONS.json`을 읽는다. 데이터의 전체 필수 필드와 초보 구간 분모를 유지한다.
2. **4단계 리소스 해독·연결**: `INPUT_RECOVERY.json`, `SOURCE_VERSION_RIGHTS_LEDGER.json`, `ASSET_CATALOG.jsonl`, `ASSET_BINDING_HINTS.json`, `ASSET_BINDING_GAPS.jsonl`에서 정확한 주소·아카이브·SHA256을 가져온다. KR4.91과 NA4.03/4.66/4.95를 분리한다. 설치파일을 실행하기 전 해독 방법과 격리 환경을 확인한다. DAT/EPF/PAL의 프레임을 직접 렌더링하고 토끼·다람쥐·캐릭터4방향의 서기/걷기/공격/피격/사망, 목도·목검의 아이콘/착용/바닥, 누리의기원 효과를 날짜가 있는 한국 스크린샷과 대조한다. 동작·방향·팔레트·음향·타격 프레임을 기록한다. 실제 확인되지 않은 상태는 NOT_RUN 또는 BLOCKED다.
3. **5단계 방식 결정**: `DEVELOPMENT_PATH_COMPARISON.json`, `SERVER_KR_COMPARISON.json`, `FEATURE_MATRIX.json`을 읽는다. 원래 클라이언트+로컬 서버와 독립 런타임을 실제 리소스·프로토콜·권리·오프라인 저장 조건으로 비교한다. Project1998은 북미4.95 대상이며 한국4.91 직결을 가정하지 않는다. Java RTK는 별도 RTK2/libGDX 경로다. 외부 무라이선스 코드를 public에 복사하지 않는다. 허용된 MIT 형식 도구는 고지 조건을 지킨다. 이 결정이 끝나기 전에 전체 게임을 새로 구현하지 않는다.
4. **6단계 초보 기능 연결**: 한국판 1~30 프로필을 선택하여 생성 → 평민1~5 → 4직업 선택 → 초보 맵 이동·충돌·전환 → 토끼/다람쥐 공격 → 분수 XP → 레벨업 → 도토리/토끼고기 → 가방 → 목도/목검 착용 → 기술 습득·시전 → NPC 구매·판매·수리 → 저장/재시작까지 연결한다. 맵/NPC 임시 수치195필드는 실제 타일·포털·NPC 배치로 교체하거나 독립 제작 배치로 명확히 확정한다. 같은 `(4,4)`을 한 지도에 겹쳐 배치하지 않는다. 수리 함수는 Project1998의 메뉴 stub을 완료 구현으로 쓰지 않는다.
5. **7단계 같은 코드 시험**: 게임이 호출하는 계산 모듈로 `BALANCE_TESTS.json`37개 조건을 실행한다. 별도의 시뮬레이션 공식으로 PASS를 만들지 않는다. 누적XP/구간XP와 습득 금전/시전MP를 분리한다. 드롭 목록을 전부 확률100%로 만들지 않는다. 원문이 ‘또는’인 목록은 독립 확률의 동시 드롭으로 바꾸지 않는다. 각 직업1~30 경제·제물·장비 강도 병목을 기록하고 필요한 제작값만 조정한다. 한국 확인값을 밸런스 조정값으로 덮어쓰지 않는다.
6. **8단계 확대**: 4직업1~30의 기능·화면·저장 검증 후31~99, 이후1차 승급과 고급 지역 순서로 확대한다. `NUMERIC_GAPS.jsonl`8,771개와 `CONTENT_FIELD_MATRIX.jsonl`의 공백을 영향도 순으로 해결한다. 미확인 캐스터 효과·동귀어진 충돌·백호왕800·불명확 NPC 호칭은 독립 보류 상태를 유지한다. 당시 원작값을 새로 찾으면 출처를 추가하고 해당 제작 필드만 교체한다.
7. **9단계 원작 비교·오프라인 완주**: 실제 화면을 조작하고 인터넷을 끈 채4직업 생성부터 목표 승급까지 완주한다. 지도·UI·색·애니메이션·음향·속도·사냥·소비·죽음·재접속을 비교하고 결과를 남긴다. 사용자에게 원작일치 검증률과 제작 입력률을 별도로 보고한다.
