# 추가 확보 경로·로그인/UI 증분

상태: 자료 준비 PARTIAL, 정적 자료 검사 PASS_DATA_SCOPE. G0/P2/게임·서버·설치기 실행 NOT_RUN. Codex 수신·채택 UNACKNOWLEDGED. 기준 P1.5는 `590bd626b63cebf6d858c8e9c1c9ce822ea0ec94`이며 기존 자료·기본 프로필은 변경하지 않았다.

## 실제 증분

- **공식 개발자 전사 신규 확보**: NDC2014_0080 「바람의 나라 복원 프로젝트」와 NDC2016_0082. 복원에 사용된 1997 리소스·1998 서버·1999 클라이언트 소스의 서로 다른 계보, 서버 전달 지도, 1998/1999 지도와 1997 타일 조합, 체험 캐릭터 및 비저장 방식을 필드 3개로 연결했다. 원 소스코드 공개·취득은 0건이다. 전사·슬라이드·영상 공개 표시는 공식 session_list의 설명이며 실제 이번 확보는 전사 HTML이다. 영상·타이밍 분석은 NOT_RUN.
- **공식 구경로 이미지 4개**: `/guide/start/img/`의 과거 실패를 반복하지 않고 CDX에서 `/guide/begin/img/` 및 `IMG/`의 실제 보관 시점을 찾아 회수했다. ba_01 초기 SETUP, ba_02 제목/로그인, ba_03 왕초보사냥터, ba_04 성황당. 2001-06~08 캡처이며 게임 빌드·작성일은 미상이다. 184×140/185×141/205×185/157×155픽셀 원본이다. ba_03의 HTML 표시 높이155와 실제185가 달라, 웹 썸네일 비율을 게임 격자로 전환해서는 안 된다.
- **580×448 로그인 참고 이미지 1개**: 아이뉴스24의 2026-04-24 보도에서 넥슨 제공·2001년 화면이라는 캡션과 함께 확보했다. 그림 자체에는 연도가 없으므로 별도 미확정 프로필이다. 첫 메뉴 `접속하기`는 2000 공식 문서의 `처음하기`와 다르다. 두 값을 합치거나 전역 기본값을 바꾸지 않는다.
- **기존 원문 새 활용**: 기존 공식 2000 basic/use HTML 2개를 동일 해시로 재열람했다. SETUP/LAN·약관 a/d·메뉴6종·초보 옷/목검 지급·1997 문서 성황당 명령의 목표시기 보강을 새 의미4개와 시기 보강1개로 정리했다. 원문 신규 취득으로 세지 않는다.
- **가이드북 서지 1개 후보**: ISBN 9788985966283의 [2001]431p와 2002 447p 기록 및 YES24의 2001 발행/2002최신판·5.05 설명이 충돌한다. 국립중앙도서관 소장/청구기호 `691.15-1-34`는 확인했다. 전체 본문·부록 CD 취득은 0건이다. ISBN만으로 특정 패치판을 단정하지 않는다.

후보는 10행이다. 원문 전체는 공개 파일에 넣지 않았다. 원문·이미지와 필요한 구자료 발췌는 `private_payload_manifest.json`의 **명시된 15파일(1,259,642바이트)**만 인계 대상으로 삼는다. 다른 다운로드나 중복 EXE는 대상이 아니다. 새 이미지 5개가 기존 P1.5 출처 레지스트리의 SHA에 없음을 확인했으며, 이를 게임 원본 자산 전부와 비교한 독립 이미지 5개라고 확대하지 않는다.

## 전달과 실행 과제

- `field_candidates_archives_ui.jsonl`: 기존 binding/requirement/content ID, 필드값·프로필·출처SHA·행/anchor·이전 입력 해시·미확정·Codex 시험.
- `sources_archives_ui.jsonl`: 신규 바이트·기존 자료 새 의미·원출처 위치를 구분한15개 출처 참조.
- `private_payload_manifest.json`: 실제 비공개 파일 집합·길이·SHA. 원문을 여러 보고서에 복제하지 않았다.
- `VALIDATION_ARCHIVES_UI.json`: 필수15파일과 실제 해시/길이, 후보10개 출처참조, 이미지5개 형식/시각 확인, 기존 정규화3파일 지문, 실행/수신 분리 등7검사.

이름 길이/허용 문자/중복·취소·실패·음향·IME·원본 UI frame/palette ID는 미확정이다. Codex는 시험 경계에서 프로필별 후보를 선택하고 UI-P15-01/02, P2-01 및 관련 생성·저장 단위만 새 입력 지문으로 검증한다. 1996 체험본의 로그인·비저장을 이번 게임의 생성·저장·계정 연동 규칙으로 채택하지 않는다.

통합 후 공개 후보·출처의 정본은 Work 루트 field_candidates.jsonl / sources_delta.jsonl 이다. 이 디렉터리의 생성 당시 파일명은 분석 이력이며, 실제 인계 파일집합은 handoff/B002/MANIFEST.json을 따른다. B002는 기존32HTML을 재포장하지 않는다.
