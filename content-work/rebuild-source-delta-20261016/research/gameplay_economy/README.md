# 몬스터·성장·상점 자료 증분

작업 `BARAM_REBUILD_WORK_SOURCE_DELTA_001`, P1.5 기준 `590bd626b63cebf6d858c8e9c1c9ce822ea0ec94`.
판정은 **자료 준비 PARTIAL / Codex 수신 UNACKNOWLEDGED / 게임 실행 NOT_RUN**이다.
기존 공식 원문을 다시 다운로드하거나 전체 44,796행을 재변환하지 않았다.

## 새로 사용할 수 있는 부분

기존 정규화 표가 본문 해시만 보존하던 몬스터 설명에서 12종의 행동을 기존 24개 판본별 monster ID에 연결했다. 곰의 비선공, 불여우의 저체력 도주, 북방 몬스터의 명시된 주문·마법 공격, 암흑사신 계열의 전체공격이 대상이다. 같은 설명이 다른 페이지·시대에 복제된 것은 독립 증거가 아니다. 정확한 수치 임계값·사거리·공격 간격·주문 native ID·범위는 미정이다. 특히 `전체공격`을 전체 맵·화면·모든 캐릭터라는 특정 기하로 해석하지 않았다.

NPC 재고 토큰과 판본별 item ID, 네 직업의 같은 이름 기술과 각 직업/나라 길드·재료, 초보 몬스터의 전리품 이름과 item ID를 새 관계 후보로 연결했다. 신규 ID를 발명하지 않고 기존 ID를 참조한다. 상점별 재고와 매입 전용 방향을 유지하며, 공통 상점 재고로 합치지 않는다. 아이템 표의 `가격`은 매입·판매 중 어느 값인지 확인되지 않았으므로 양쪽 실제 거래가는 null이다.

동일 `KR_GUIDE_2001_SNAPSHOT`의 같은 HTML 안에도 진마반지 가격 충돌이 있다. 기존 두 item ID의 원문 행과 서로 다른 가격을 증거에 연결하고 선택값을 null로 보존했다. 연도 프로필 분리만으로는 해결되지 않으며 첫 행 선택·평균·0 추가는 금지한다. 같은 이름의 중복 장비 행, 토끼고기처럼 알려진 획득명에 대응하는 item 표 행이 없는 경우, 특정 백씨상인에게만 허용된 판매는 각각 보류 상태를 유지한다.

제작 장소에서 동시기 상인 이름으로 이어지는 4개 후보는 **장소에 따른 추론**이다. 그 NPC에게 실제 제작 대화나 스크립트가 존재한다고 확정하지 않는다. 기존의 한정 이벤트 조건·재료·미상 성공률·실패손실·비용을 바꾸지 않는다.

## Codex가 선택적으로 이어갈 일

먼저 후보의 `old_value_or_hash`와 선택한 P1.5 입력 지문을 비교한다. 프로필·동명이인·공백만 다른 표기·같은 페이지 중복행을 검토한 뒤 시험 경계에서 선택적으로 채택한다. 자료를 읽은 사실만으로 수신·채택 기록을 만들지 않는다.

1. 곰의 피격 전/후, 불여우의 체력 감소 전/후, 북방 주문과 사신의 실제 대상 범위를 관측한다.
2. NPC별 판매/매입 방향·제한 상인·실제 가격과 네 직업의 서로 다른 학습 제한/재료 소비를 검증한다.
3. 토끼고기 등 미연결 아이템은 원문 표의 생략인지 다른 표·원본 ID가 있는지 조사하고 신규 안정 ID는 통합 담당이 결정한다.
4. 한국 스폰 수·구역·재출현 시간·정확 AI 시간/반경, 전체 경험치 곡선·승급, 제작/수리 확률·비용 공식은 이번 자료로 해결되지 않았다. 근거 없는 값으로 채우지 않는다.

공통 도구·게임·상태·기준 입력은 읽기 전용으로 유지했다. Work 공개 변경은 본 연구 디렉터리 안에만 있다. 최종 배치 발행·Git·지속 저장은 통합 담당이 수행한다.

통합 후 공개 후보·출처의 정본은 Work 루트 field_candidates.jsonl / sources_delta.jsonl 이다. 이 디렉터리의 생성 당시 파일명은 분석 이력이며, 실제 인계 파일집합은 handoff/B002/MANIFEST.json을 따른다. B002는 기존32HTML을 재포장하지 않는다.
