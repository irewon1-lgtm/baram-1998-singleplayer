# Work 자료 증분 독립 AI 감사

기준 P1.5 `590bd626b63cebf6d858c8e9c1c9ce822ea0ec94`, 작업 `BARAM_REBUILD_WORK_SOURCE_DELTA_001`.

감사는 자료의 바이트·참조·명시된 문구와 후보 관계를 확인했다. 한국 원작 전체 정확성, 게임 동작, Codex 수신·채택, G0/P2 또는 실기기 시험은 판정하지 않았다. 이 감사 작업은 원본 실행 파일·서버·SQL을 실행하지 않았고 발행 B001을 수정하지 않았다.

## B001

고정 ZIP의 9개 파일이 staging과 정확히 일치하며 CRC 오류가 없다. SHA256은 `b61c169c899853c0a90849f81174d76c8503e6827ef3244ca489aff2b721e6af`이다. 기존 stable ID 참조 36개와 연결 ID, 비공개 레코드·길이·해시 참조에서 오류를 발견하지 않았다.

Pillow를 사용하지 않는 GIF block parser로 기존 GIF 13개의 실제 GCE 선언 지연·차원·프레임 수를 독립 대조했고 모두 맞았다. 기존 Effect 시퀀스의 frame/delay/행·바이트 offset과 파생 타임라인의 연결도 일치했다. 이 결과는 GIF 선언 시간을 게임 명중·오디오·재행동 시간으로 확정하지 않는다. 기존 RGB 비교는 새로운 렌더러로 재시험하지 않았으므로 그 범위를 새 성과로 세지 않았다. 2002년 참고 GIF와 클라이언트 연대 미확정도 유지돼 있다.

초기 `validate_batch.py`는 바이트 변조·누락·0개 파일·깨진 payload 경로를 거부했지만, 다음 6종은 잘못 PASS했다. 존재하지 않는 기존 stable ID, 요구 ID, private record ID, 잘못된 private SHA, manifest에 자체 허용한 가짜 binding ID, 틀린 기준 manifest 지문이다. B001 실제 자료에 이 6종 오류가 있다는 뜻은 아니다.

추가 `verify_evidence_refs.py`에서 정상 B001 118검사와 위 6종 실패 사본을 다시 시험했고 정상만 통과했다. 초기 결함과 개선된 검사의 지문·결과는 각각 `B001_INDEPENDENT_AUDIT.json`, `EVIDENCE_GUARD_REGRESSION.json`에 기록했다. 기존 고정 B001을 다시 패키징할 필요 없이 추가 검사 결과를 함께 인계할 수 있다.

ZIP에서 실행파일·SQL·폰트·서명키 확장자와 강한 자격증명 표식은 발견하지 않았다. 이는 한정된 파일명·패턴 검사이며 악성코드 부재 또는 모든 비밀 부재 보증이 아니다.

## Gameplay/economy 준비 자료

126개 공개/비공개 후보를 2,508개 정적 조건으로 검사했고 오류가 없었다. 공개↔비공개 레코드의 canonical SHA, 기준 정규화 4파일의 길이·해시·행 수, 기존 ID·원문 위치·동일 프로필 연결, 기존 HTML 32개 실제 바이트 해시를 확인했다. HTML 32개는 재확보 성과가 아니며 최종 배치가 P1.5의 정확한 해시·위치를 참조하면 다시 포함하지 않아도 된다.

행동 의미 24건은 생성 스크립트의 regex와 별개인 HTMLParser로 해당 원문 행의 명시 문구를 대조했다. 천오·신몽의 주문명도 원문에 있다. 상점의 판매/매입 방향, 미확정 실제 가격, 동명 아이템 후보, 드롭 확률·수량 미확정, 제작 장소 관계가 추론이라는 표시는 보존돼 있다. 동시기 진마반지 가격 충돌도 임의 선택 없이 남겨져 있다.

결과는 `GAMEPLAY_ECONOMY_INDEPENDENT_AUDIT.json`에 기록했다. 이 감사는 명시 문구 및 관계 제약의 자료 검토다. 전체 역사적 의미와 실행 결과의 검증이 아니며 최종 B002 ZIP의 필수 집합·바이트·참조 검사는 별도로 해야 한다.

## B002 최종 패키지 추가 검사

실제 B002의 payload 28개와 control 2개, 후보 154개를 추가 574조건으로 검사했고 오류가 없었다. ZIP CRC와 staging 30개 파일 전체가 정확히 일치했다. 해당 ZIP은 613,492바이트, SHA256 `dc87687e7260ee4f0c3777bbb46559a67be64f7050195baf6650a29d1c068aee`다. 이후 ZIP을 변경하면 이 지문에 대한 결과를 재사용할 수 없다.

아카이브/UI의 payload 15개 중 신규 원문 바이트는 13개(GIF 4, JPEG 1, HTML 8)이며 나머지 2개는 기존 원문 발췌와 전사문 위치를 정리한 파생 파일이다. 전체 책이나 소스코드를 신규 확보한 것이 아니다. 신규 13출처의 실제 바이트·길이·해시, 기존 원문 발췌 5개의 원본 행, NDC 전사문 anchor와 서지 ISBN·431/447쪽을 확인했다. 새 그림 5개를 직접 열어 메뉴 글자와 장면을 확인했다. 보도 그림의 `접속하기`와 과거 문서의 `처음하기` 충돌, 연대·클라이언트 빌드 미확정이 유지됐다.

게임플레이 비공개 126후보는 앞선 감사 후 의미값 변경이 없었다. 후보의 미채택 상태와 Codex 관측 과제가 유지되며, 실행파일·SQL·폰트·서명키 확장자 및 강한 비밀 표식은 발견하지 않았다. 자세한 범위는 `B002_INDEPENDENT_AUDIT.json`에 기록했다. 이 결과도 자료 검사이며 원작 전체·G0/P2 실행 판정은 아니다.

## 경계

감사 산출물만 Work 허용 경로의 `research/audit/`에 작성했다. 실패시험 사본은 임시 디렉터리에서 실행 후 제거했다. 기준 자료와 발행 배치에 쓰기를 하지 않았다. 북미 원천 FAIL 154건이나 공통 importer 상태를 변경하지 않았다.
