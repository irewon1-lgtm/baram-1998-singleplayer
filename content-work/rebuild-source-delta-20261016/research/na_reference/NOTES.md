# 북미 참고 원본의 새 해석

고정 FAIL154는 변경하지 않았다. Path99 실패115행 가운데13기술의15개 player:addSpell 호출 위치를 새로 연결했다. 이는 원본 누락 정의의 일괄 해결이나 한국 원작 채택이 아니다. 일반 직업학습 query는 Paths 조인이 아니라 path0/인자class1/class2 필터를 사용한다. 따라서 임의 Path99 직업행을 만들어 참조검사를 통과시키는 수정은 부적절하다. 정확한 데이터는 비공개 grant_routes.json에 한 번만 둔다.

spot_traps의 참고 프로젝트 주석과 RTK 실제 grant 코드가 충돌한다. 주석만 읽고 펫 전용으로 확정하지 않는다. 실행·원작 판정은 Codex 관측 과제다.

통합 후 공개 후보·출처의 정본은 Work 루트 field_candidates.jsonl / sources_delta.jsonl 이다. 이 디렉터리의 생성 당시 파일명은 분석 이력이며, 실제 인계 파일집합은 handoff/B002/MANIFEST.json을 따른다. B002는 기존32HTML을 재포장하지 않는다.
