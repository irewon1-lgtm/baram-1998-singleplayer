# 한국 지도·NPC 증분 자료

기준은 P1.5 `590bd626b63cebf6d858c8e9c1c9ce822ea0ec94`이다. 이 조사에서 원본 신규 고유 자산은 0개이며, 기존 자료의 새 연결과 화면 의미 4건을 후보로 인계한다. 기존 44,796행의 재생성·공통 데이터 변경·클라이언트/서버 실행은 하지 않았다.

## 지도 정체성에서 발견한 새 문제

공식 `고구려_all02.pcx`와 Paststory75의 `[2000년] 4.70 버전 신국내성지도` 첨부는 같은 도시 파노라마의 계보다. 중앙 궁궐·북쪽 설원·서남쪽 성벽과 마을·물길의 배치가 일치한다. 두 이미지의 크기는 1451×1451 및 500×500 픽셀이며, 16×16 명도 축소 상관계수는 0.991449이다. 실제 바이트 해시와 비교 수치는 `INPUT_AND_VISUAL_COMPARISON.json`에 있다.

이는 해시가 같은 파일이라는 뜻이나 서로 독립적인 두 지도 원전이라는 뜻이 아니다. 또한 4.70이라는 시대 설명은 2014년 회고 게시글의 귀속이므로 이를 원본 실행 판본 확정으로 승격하지 않는다. 새 결론은 **2001년에 보관된 공식 전체 지도 이미지를 곧바로 2001 일반 국내성의 타일 정답으로 채택할 수 없다는 구체적인 판본 충돌**이다. 별도 신국내성 후보로 비교하고, 기본 도시 지도는 선택한 실행본·동시기 지도와 따로 대조해야 한다. 현재 채택값은 바꾸지 않았다.

부여 CRC 실패 ZIP을 위한 정확 CDX 조회에서는 `map_bu_all02.zip`의 기존 20010612060002 캡처만 반환했다. 동일 원 URL의 2002년 캡처, `all01`, `all03`, `guide/middle` 경로는 해당 조회 범위에서 빈 결과였다. 이는 아카이브 전체의 부재 증명이 아니다. 기존 ZIP의 CRC FAIL은 유지한다. 다른 옛 부여성 지도 미러인 BaramInside `memory/1738`은 검색에서 발견했으나 실제 요청은 403이어서 원문·첨부 확보로 세지 않았다.

CDX에서 발견한 `map_size.gif`를 실제 취득했지만 SHA256이 기존 P1.5 자산과 같았다. 신규 파일 확보 성과로 계산하지 않는다. 광범위 도메인 wildcard 두 조회는 관련 없는 대량 결과가 한도에 걸려 폐기했으며, 정확 경로 CDX 결과만 인계한다.

## NPC 화면에서 추가로 읽은 부분

- `arc006.gif`: 화면 제목이 순이네푸줏간이고, 순이의 거래 완료 발화와 적호의가죽을 요청하는 플레이어 발화가 보인다. 기존의 네 길드 사범 외형 자료 외에 순이라는 이름과 점원 외형의 화면 근거를 추가했다. 정확 원본 대사는 비공개 `semantic_records.jsonl`에 한 번만 기록했다.
- 같은 화면의 200전은 **표시된 거래 문장의 금액**이다. 수량은 보이지 않으므로 1개 단가나 매입가로 확정하지 않았다. 플레이어 요청과 NPC의 판매 완료 표현은 NPC→플레이어 거래 후보를 지지하지만 연속 실행·가방/금전 변화는 관찰하지 않았다. 성공 문장 한 장으로 실패·거절·취소·재방문 분기를 채우지 않았다.
- `ba_018.gif`: 고구려좌성황 화면에 왼쪽의 밝은 머리/머리덮개와 밝은 긴 옷을 입은 담당 인물, 유령 형태 인물 둘이 보인다. 부활 서비스 설명과 화면 역할을 연결했다. 인물 이름이나 숫자 native ID, Body/Head/옷/팔레트 ID는 미확정이며, 기존 재구성 대사 “다시 일어나세요”를 원문으로 인증하지 않는다.

말풍선·카운터 가림이 있으므로 후보의 픽셀 영역은 정밀 sprite cutout이나 게임 좌표가 아니다. MonsterEPF 일치 실패만으로 이 인물들이 원본 자산에 없다고 결론 내리지 않는다. 사람형 부품 합성을 P2에서 비교할 수 있게 참조만 제공한다.

## 실제 검사와 다음 시험

정상 입력 4개의 SHA256·이미지 해독을 검사했다. 후보 4행의 기존 binding/content/requirement ID 참조를 확인했고, 손상 입력 사본은 해시 오류로 거부되어 출력 파일을 만들지 않았다. `VALIDATION_MAPS_NPC.json`의 PASS는 이 범위의 자료 검사다. G0/P2·원작 판본 확정·실제 거래·부활·런타임 시험은 NOT_RUN이다.

Codex는 시험 경계에서 후보를 선택하고, 지도 정체성 비교(P2-01), 사람형 부품·가림·방향 비교(P2-02), 선택한 판본의 거래/부활 상태 관측만 해당 새 지문으로 시험해야 한다. 수신·채택은 UNACKNOWLEDGED다.

남은 지도/출구/귀환 공백은 실제 MAP ID, 같은 판본의 사대문 출입·도착칸, 국내/부여별 귀환 위치, 정확한 실내 연결이다. 다음 자료 검색은 손상 부여 원 URL의 별도 웹 아카이브/OASIS 사본과 당시 자료 CD/도움말의 동명 PCX에 집중한다. NPC는 순이의 exact build·native ID·각 방향 합성, 성황 담당자의 이름·원본 발화·부활 전후 조건이 남았다.

공개 산출물에는 전체 원문/그림/음향을 넣지 않았다. 기존 원본은 P1.5 패키지의 상대경로+해시로 참조한다. 새 비공개 주석·검색 영수증은 별도 증분 묶음에 넣을 수 있으며, 기존 인계 ZIP을 다시 포장할 필요가 없다.

통합 후 공개 후보·출처의 정본은 Work 루트 field_candidates.jsonl / sources_delta.jsonl 이다. 이 디렉터리의 생성 당시 파일명은 분석 이력이며, 실제 인계 파일집합은 handoff/B002/MANIFEST.json을 따른다. B002는 기존32HTML을 재포장하지 않는다.
